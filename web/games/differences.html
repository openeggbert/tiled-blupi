Game Differences

A detailed comparison of Speedy Blupi and Speedy Blupi II from the perspective of tiled-blupi.

Summary

Both games share the same BLP binary format (same offsets, same structure, same 50,468-byte file size). The differences are exclusively in content: more tiles per tileset, more object types, and different default minor_version values.

Common Structure

These aspects are identical between SB1 and SB2:

  • BLP file size: 50,468 bytes
  • BLP major_version: 1
  • Foreground layer offset: 0x0364
  • Decoration layer offset: 0x5184
  • Object array offset: 0x9FA4
  • Object struct size: 48 bytes (0x30)
  • All object struct field offsets
  • Tile storage formula: column-major uint16
  • Level naming: WORLD###.BLP, u###-###.blp
  • Player start BLP type IDs: 200–203
  • Player Start tileset: 4 identical tiles
