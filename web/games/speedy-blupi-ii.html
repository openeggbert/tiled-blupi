Speedy Blupi II

The sequel to Speedy Blupi (1999) — tiled-blupi support details, including the 10 additional object types.

Game Overview

Speedy Blupi II is the direct sequel to Speedy Blupi, featuring new environments, new object types, and additional content. Like its predecessor, it stores levels in the same BLP binary format with the same fixed 100×100 tile grid structure. The key difference from a tiled-blupi perspective is a larger set of tiles in all tilesets and 10 additional object types.

Opening a SB2 Level

  1. Open speedyblupi2.tiled-project in Tiled.
  2. File → Open → navigate to DATA/.
  3. Select a WORLD###.BLP file.
  4. Choose format: Speedy Blupi 2 level.
