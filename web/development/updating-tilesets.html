Updating Tilesets

This page explains how to modify the TSX tileset files in tiled-blupi: adding new tiles, removing tiles, changing tile images, and modifying tile properties. It also explains how tileset changes affect the sblv.js extension behavior.

Understanding TSX and sblv.js Coupling

The TSX files and the sblv.js extension are tightly coupled through tile indices:

  • The tile id in a TSX file (0-based integer) directly corresponds to the BLP tile value in tile layers, or to the position in itemTypesArray for the object-types tileset.
  • If you add a tile with an id that is not at the end of the sequence, you shift all subsequent tile IDs, which breaks the mapping.
  • Always add new tiles at the end of a tileset.

Adding a New Tile to a Tile Layer Tileset (element or explo)

To add a new terrain or decoration tile:

  1. Create the PNG image for the tile.
  2. Open the TSX file (e.g., element.tsx).
  3. Find the highest existing tile id — let us call it N.
  4. Add a new <tile id="N+1"> block with the image path.
  5. Update tilecount in the <tileset> root element to N+2.
No sblv.js change needed for adding terrain or decoration tiles, because sblv.js does not have hard-coded tile IDs for these layers — it just reads raw uint16 values from the BLP file and maps them through the tileset's firstgid. As long as the new tile's id matches the BLP value you want to support, it works automatically.

Adding a New Tile to the object-types Tileset

This requires a matching change in sblv.js. See Adding Object Types for the full procedure.

Changing a Tile's Image

To replace the PNG image of an existing tile:

  1. Replace the PNG file in the game's image directory with the new image (same filename, same dimensions).
  2. No TSX change is needed — the TSX still references the same filename. Tiled will automatically show the new image on next load.

Alternatively, if you want to use a differently named or differently located file:

  1. Update the source attribute in the tile's <image> element.
  2. Tiled will use the new path on next project open.

Changing Tile Properties (hflip, class)

To add or change a tile property:

  1. Open the TSX file in a text editor.
  2. Find the <tile id="N"> block for the target tile.
  3. Add or modify the <properties> child element:
<tile id="2">
  <image .../>
  <properties>
    <property name="hflip" type="bool" value="true"/>
    <property name="class" value="Blupi"/>
  </properties>
</tile>
Effect on sblv.js: The class property is read by sblv.js during the write phase to distinguish player starts (class=Blupi) from regular objects. Changing a tile's class could cause sblv.js to misidentify it. The hflip property is read by sblv.js to set the horizontal flip flag on player start objects. Only change these properties if you understand the consequences.

Modifying tileoffset

The tileoffset in explo.tsx (<tileoffset y="64"/>) affects rendering only — it is a Tiled display feature. Removing or changing it does not affect what gets written to the BLP file. It only changes how tiles look in Tiled's canvas.

After Changing a TSX File

  1. Save the TSX file.
  2. In Tiled, use View → Reload Tilesets or close and reopen the project to pick up the changes.
  3. Open a level file to verify the tileset looks correct.
