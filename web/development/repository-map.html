Repository Map

This page is a fully annotated directory tree of the tiled-blupi repository. Every file and directory is explained.

Top-Level Structure

tiled-blupi/
├── README.md                          ← User-facing project description and setup instructions
├── .gitignore                         ← Git ignore rules (ignores OS files, editor temp files)
├── speedy-blupi-1/                    ← Complete project for Speedy Blupi 1
└── speedy-blupi-2/                    ← Complete project for Speedy Blupi 2

speedy-blupi-1/ (SB1 Project)

speedy-blupi-1/
├── speedy-blupi-1.tiled-project       ← Tiled project file (JSON); entry point for Tiled
├── extensions/
│   └── sblv.js                        ← Scripted map format extension (513 lines)
│                                         Registers format "sblv"; reads and writes .blp files
└── tilesets/
    ├── element.tsx                    ← Foreground terrain tileset; no tileoffset
    ├── explo.tsx                      ← Decoration tileset; tileoffset y=64
    ├── object.tsx                     ← General object display tileset
    ├── object-types.tsx               ← Object types tileset; 34 tiles + tile 0 (Endpoint class)
    ├── player-start.tsx               ← Player start tileset; 4 tiles; class=Blupi; tiles 2-3 hflip
    ├── blupi000.tsx                   ← Blupi character sprite set 0
    ├── blupi001.tsx                   ← Blupi character sprite set 1
    ├── blupi002.tsx                   ← Blupi character sprite set 2
    └── blupi003.tsx                   ← Blupi character sprite set 3

speedy-blupi-2/ (SB2 Project)

speedy-blupi-2/
├── speedy-blupi-2.tiled-project       ← Tiled project file; registers "sb2lv" format
├── extensions/
│   └── sblv.js                        ← SB2 extension (552 lines); major_version=2; 44 types
└── tilesets/
    └── (identical set of TSX files as SB1, but with different PNG paths)

What Is Not in the Repository

The following items are required for the project to work but are NOT in the repository:

  • PNG image files — All tile images (referenced by TSX files) come from the game installation. They are copyrighted and not redistributed.
  • Level files (.blp) — The actual game levels are in the game's level/ directory, not in the repository.
  • Game executable — The Speedy Blupi game itself is not included.
