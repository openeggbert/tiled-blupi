Installation

Detailed instructions for installing tiled-blupi into your Speedy Blupi or Speedy Blupi II game directory, including how to verify that Tiled loaded the extension correctly.

Overview

tiled-blupi requires no installer. Installation means copying a single folder from the repository into the correct location inside your game's installation directory. The only software you need installed is Tiled itself.

You must perform the installation once per game. If you edit both Speedy Blupi and Speedy Blupi II, you install separately into each game directory.

Step 1 — Get the Repository

Choose one of the following methods:

Option A: Git Clone (recommended)

git clone https://github.com/openeggbert/tiled-blupi.git

This creates a local copy that you can update with git pull.

Option B: Download ZIP

  1. Go to github.com/openeggbert/tiled-blupi.
  2. Click the green Code button, then Download ZIP.
  3. Extract the ZIP archive to a convenient location.

Step 2 — Locate Your Game's Installation Directory

You need to find where the game is installed. Common locations:

PlatformTypical path
Windows (standalone)C:\Program Files\Speedy Blupi\ or C:\Games\Speedy Blupi\
Windows (Steam)C:\Program Files (x86)\Steam\steamapps\common\Speedy Blupi\
Windows (GOG)C:\GOG Games\Speedy Blupi\
Linux (Wine)Wherever the Wine prefix places the game

You can confirm you have the right directory if it contains a DATA/ subfolder with .BLP files inside.

Step 3 — Copy the tiled Folder

✓ Verified from README.md
"Simply take the tiled folder for the game you want to edit and place it directly in the game's install folder."

For Speedy Blupi:

cp -r "tiled-blupi/Speedy Blupi/tiled" "/path/to/SpeedyBlupi/"
# Windows: copy the folder "Speedy Blupi\tiled" into the game dir

For Speedy Blupi II:

cp -r "tiled-blupi/Speedy Blupi II/tiled" "/path/to/SpeedyBlupiII/"

After copying, the game directory should have this structure:

SpeedyBlupi/
├── tiled/                         ← new folder you just copied
│   ├── speedyblupi.tiled-project  ← Tiled project file (open this)
│   ├── extensions/
│   │   └── sblv.js                ← the format extension
│   └── tilesets/
│       ├── object.tsx
│       ├── element.tsx
│       ├── explo.tsx
│       ├── blupi000.tsx
│       ├── blupi001.tsx
│       ├── blupi002.tsx
│       ├── blupi003.tsx
│       ├── Player Start.tsx
│       ├── Object Types.tsx
│       ├── object/                ← 246 PNG files
│       ├── element/               ← 187 PNG files
│       ├── explo/                 ← 54 PNG files
│       ├── blupi000/ … blupi003/  ← 291 PNG files each
│       ├── Player Start/          ← 4 PNG files
│       └── Object Types/          ← 34 PNG files
├── DATA/
│   ├── WORLD001.BLP
│   └── …
├── IMAGE16/
└── Blupi.exe

Step 4 — Open Tiled and Load the Project

  1. Launch Tiled.
  2. Go to File → Open.
  3. Navigate to <game directory>/tiled/.
  4. Open speedyblupi.tiled-project (SB1) or speedyblupi2.tiled-project (SB2).

The project panel on the left will now show two folders:

  • tilesets — the tileset files
  • DATA — the game's level files

Step 5 — Verify the Extension Loaded

To confirm sblv.js loaded successfully:

  1. In Tiled, go to File → Open.
  2. Navigate to the DATA/ folder.
  3. Select any WORLD###.BLP file.
  4. If the extension is loaded, Tiled will ask you to choose a format. You should see:
    • Speedy Blupi level (for SB1)
    • Speedy Blupi 2 level (for SB2)

If the format is not listed, see Troubleshooting.

Updating tiled-blupi

If you installed via git clone, run git pull in the repository directory to get updates. Then copy the updated tiled/ folder into the game directory again, replacing the old one.

If you downloaded a ZIP, download and extract the new version and repeat the copy step.

Uninstalling

Delete the tiled/ folder from the game directory. This removes the extension, project file, tilesets, and PNG images. The game itself is not affected.

Note — multiple games
If you have both Speedy Blupi and Speedy Blupi II, install into each game directory separately. Each game gets its own tiled/ folder from the corresponding repository subfolder. You can have both projects open in Tiled simultaneously using two Tiled windows or by switching projects via File → Recent Projects.
