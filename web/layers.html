Layers

Every Speedy Blupi level opened by tiled-blupi is represented in Tiled as four distinct layers. This page explains each layer's purpose, how it maps to the BLP binary format, which tileset it uses, and what editing restrictions apply.

✓ Verified from sblv.js
Layer names, types, tileset assignments, and BLP offsets are all derived directly from the read() function in sblv.js.

Layer Overview

Layer Name Tiled Type Tileset BLP Offset BLP Size Editable
Foreground Tile Layer object.tsx 0x0364 20,000 B Yes
Decoration Tile Layer explo.tsx 0x5184 20,000 B Yes
Objects Object Layer Object Types.tsx + Player Start.tsx 0x9FA4 9,600 B Yes
Background Image Layer External (IMAGE16/ or IMAGE08/) — — No (locked)

Foreground Layer

Purpose

The foreground layer contains the main gameplay tiles — solid ground, platforms, walls, ladders, and any other interactive surfaces that the player can walk on, jump through, or collide with. In Tiled, this is a standard tile layer that fills the entire 100×100 grid.

Tileset: object.tsx

The object tileset provides the visual graphics for foreground tiles. It has 246 tiles (SB1) or 441 tiles (SB2), numbered 0 to 245 (SB1) or 0 to 440 (SB2). Each tile is a 64×64 pixel PNG image.

BLP Storage

Stored at file offset 0x0364 as a 100×100 array of uint16 little-endian values in column-major order. The address of tile (x, y) is: 

offset = 0x0364 + (y + 100 * x) * 2

A value of 0xFFFF means the cell is empty. All other values are 0-based tile indices into the object tileset.

Editing

  • Select the Foreground layer in the Layers panel.
  • Select tiles from the object tileset in the Tilesets panel.
  • Paint with the Stamp Brush (B) or Eraser (E) tools.
  • All 100×100 cells can be freely edited.
  • Using the Eraser sets the cell to 0xFFFF (empty) in the BLP file.

Decoration Layer

Purpose

The decoration layer adds visual depth to levels — large plants, rocks, structural background elements, and other non-interactive decorations. These tiles appear behind the foreground tiles and the player, but in front of the background image.

Tileset: explo.tsx

The explo tileset is used for decoration tiles. It has 54 tiles (SB1) or 100 tiles (SB2). Critically, this tileset has a tile offset of y=64 pixels defined in the TSX file: 

<tileoffset x="0" y="64"/>

This means that when Tiled renders an explo tile, it draws it 64 pixels lower than the tile's logical grid position. A decoration tile placed at grid row 5 will visually appear at the position of grid row 6 (5 × 64 + 64 = 6 × 64). This matches the game's behavior, where decoration elements overlap the row below their position.

BLP Storage

Stored at file offset 0x5184, same format as the foreground layer: 

offset = 0x5184 + (y + 100 * x) * 2

Editing

  • Select the Decoration layer in the Layers panel.
  • Select tiles from the explo tileset in the Tilesets panel.
  • Remember that tiles appear 64 pixels lower than their grid position suggests. Plan placement accordingly.
  • To see where a decoration tile will appear in-game, look one row below where you place it in Tiled.

Objects Layer

Purpose

The objects layer contains all interactive game objects: enemies, collectibles, hazards, moving platforms, and player starting positions. In Tiled, each object is represented as a tile object (a rectangle with an associated tile image) at a specific position on the canvas.

Tilesets

Two tilesets are used for the Objects layer:

  • Object Types.tsx — for all game objects (enemies, items, etc.). Has 34 tiles (SB1) or 44 tiles (SB2). The tile index matches the ObjectTypes enum index. Tile 0 in this tileset has the class Endpoint and is used to mark movement endpoints.
  • Player Start.tsx — for player spawn points. Has 4 tiles (for players 1–4). Tiles 2 and 3 have hflip enabled in the TSX so players 3 and 4 appear as horizontally mirrored versions. All 4 tiles have the class Blupi.

BLP Storage

The object array starts at offset 0x9FA4. There are 200 slots, each 48 bytes (0x30). A slot is empty if its first 4 bytes (the type field) are zero. The extension reads all 200 slots and creates a Tiled object for each non-empty slot. 

slot_base = 0x9FA4 + slotIndex * 0x30

Object Position

Object positions in the BLP file are tile coordinates (0–99 for both x and y). In Tiled, they appear at pixel positions: 

tiled_pixel_x = blp_tile_x * 64
tiled_pixel_y = blp_tile_y * 64

On save, the reverse conversion is applied. If you drag an object to a non-aligned position in Tiled, it will be snapped to the nearest tile on write (integer division by 64). Use View → Snapping → Snap to Grid in Tiled to avoid misalignment.

Object Count Limit

Each level supports a maximum of 200 objects. If you add more than 200 objects in Tiled, the extension will only write the first 200 — with no error or warning. Keep your object count at or below 200.

Editing

  • Select the Objects layer.
  • Use the Select Objects tool (S) to select, move, or delete objects.
  • Use the Insert Tile Object tool with a tile from the Object Types tileset to add new objects.
  • In the Properties panel, set the type property to the desired ObjectTypes enum value.
  • Set endpoint, timing, and other properties as needed for the object type.

Background Layer

Purpose

The background layer displays the level's background image — the scenic backdrop behind all gameplay elements. It is purely visual and has no gameplay effect in the editor.

How it is loaded

When sblv.js reads a level, it reads the background property from the BLP header (offset 0x14), constructs an image filename from the index, and loads that file from the game's IMAGE16/ (or IMAGE08/) folder.

The background image is added as a Tiled image layer named Background, positioned at (0, 0), and locked so it cannot be accidentally edited.

Limitations

  • The background image is not stored in the BLP file — only the index number is. The image itself comes from the game installation.
  • If you change the background map property in Tiled, the displayed background image does not update automatically. You must close and reopen the level file to see the new background.
  • The background layer is read-only (locked) in Tiled. You can only change the background by editing the background map property.
  • If the game's IMAGE16/ or IMAGE08/ folder cannot be found (e.g., the tiled/ folder is not inside the game directory), the background layer may be blank or absent.
