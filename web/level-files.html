Level Files

Everything about Speedy Blupi's .blp level file naming conventions, which files are safe to open, and how to locate them on your system.

✓ Verified from README.md
"Levels are found in the DATA folder, named WORLD###.BLP for standard levels, and u###-###.blp for custom levels; there are other files in the folder, but trying to open them will just cause errors."

Standard Levels: WORLD###.BLP

Standard (retail) levels are named WORLD###.BLP where ### is a zero-padded three-digit number starting from 001. Examples: WORLD001.BLP, WORLD002.BLP, …, WORLD025.BLP.

  • These are the game's built-in levels.
  • The filename is in uppercase on Windows filesystems.
  • They are located in the DATA/ subfolder of the game installation.
  • You can edit and save over these files (with the game closed), but always keep backups.

Custom Levels: u###-###.blp

Custom (user-created) levels are named u###-###.blp where each ### is a three-digit number. Examples: u001-001.blp, u001-002.blp.

  • These are user-created or third-party levels.
  • The filename is typically in lowercase.
  • Also located in the DATA/ folder.
  • The numbering scheme may correspond to a world/level organization system.

Files to Avoid

The DATA/ folder contains other .blp files that are not level files. These may be sprite data, game state files, or other binary data. Attempting to open them with the Speedy Blupi level format in Tiled will cause errors, because they do not have major_version = 1 at offset 0x00.

Do not open non-level .blp files
Only open WORLD###.BLP and u###-###.blp files. Opening other .blp files will cause the extension to report an error and may display garbage data.

File Location

After copying the tiled/ folder, the layout is:

Game installation directory/
├── tiled/                ← tiled-blupi files (just installed)
├── DATA/
│   ├── WORLD001.BLP      ← editable level file
│   ├── WORLD002.BLP      ← editable level file
│   ├── …
│   ├── u001-001.blp      ← custom level file
│   └── (other .blp files — do not open these)
├── IMAGE16/
│   └── (background images)
└── IMAGE08/
    └── (background images, low-color fallback)

From the Project panel in Tiled, the DATA folder is shown (because it is listed in the project file's folders array as "../DATA"). You can double-click a WORLD###.BLP file there to open it directly.

Creating a New Level File

The extension does not support creating a new level from scratch in Tiled. To create a custom level:

  1. Copy an existing WORLD###.BLP file and rename it to u###-###.blp.
  2. Open the copy in Tiled.
  3. Edit it completely — change all tiles, objects, and properties.
  4. Save it to the DATA/ folder.

The new file will have the same 50,468-byte structure as all other level files.
