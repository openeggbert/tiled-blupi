tiled-blupi Documentation

Complete reference for the Tiled map editor extension that reads and writes
Speedy Blupi and Speedy Blupi II binary level files (.blp)

tiled-blupi is an open-source project that lets you open, edit, and save level files from the classic platform games Speedy Blupi and Speedy Blupi II using the free Tiled map editor. It provides a JavaScript extension (sblv.js) that teaches Tiled how to read and write the proprietary binary .blp level format, along with complete tileset packs so every tile and object appears correctly on screen.

What is tiled-blupi?

The Speedy Blupi games store their levels in a proprietary binary format with the extension .blp. This format is not natively understood by any general-purpose map editor. tiled-blupi solves this by providing a scripted map format for the Tiled editor — a free, open-source map editor that supports custom format plugins written in JavaScript.

The repository contains three kinds of files:

ComponentFile(s)What it does
JavaScript extension extensions/sblv.js Registers a custom map format with Tiled. Called by Tiled on every open and save of a .blp file. Parses binary data into Tiled layers and objects, and serialises them back.
Tiled project file *.tiled-project Tells Tiled where to find the extension, which folders to show in the project panel, and defines the custom Object class and ObjectTypes enum used in the Properties panel.
TSX tilesets tilesets/*.tsx XML files describing each tileset's tiles, their images, optional tile classes, horizontal-flip flags, and tile offsets. Tiled reads these to display tiles correctly.
PNG tile images tilesets/<name>/N.png 64×64 PNG images, one per tile, extracted from the game. These are the visual graphics that appear in the Tiled canvas and tile picker.

Supported Games

Game Repository Folder Project File Format ID Format Name in Tiled Default minor_version
Speedy Blupi Speedy Blupi/tiled/ speedyblupi.tiled-project sblv Speedy Blupi level 2
Speedy Blupi II Speedy Blupi II/tiled/ speedyblupi2.tiled-project sb2lv Speedy Blupi 2 level 3

The two games share the same binary level structure (50,468 bytes, fixed 100×100 tile grid, identical byte offsets for all decoded fields). The differences are in the number of tiles per tileset and the set of supported object types — Speedy Blupi II adds 10 extra object types. See Game Differences for a full comparison.

How It Works — Step by Step

  1. Copy the tiled folder from the repository into your game's installation directory. After this, your game folder contains a tiled/ subdirectory alongside the game's DATA/ folder.
  2. Open the project file (speedyblupi.tiled-project or speedyblupi2.tiled-project) in Tiled. This causes Tiled to load extensions/sblv.js, which registers the custom map format and makes it available in the open/save dialogs.
  3. Open a level file with File → Open. Navigate to the game's DATA/ folder and select a WORLD###.BLP or u###-###.blp file. When prompted, choose the correct format (Speedy Blupi level or Speedy Blupi 2 level).
  4. Tiled calls sblv.js which reads the binary file: parses the 7 known header fields, reads the 100×100 foreground tile grid (column-major uint16 array), reads the 100×100 decoration tile grid, and reads up to 200 object structs (48 bytes each). The result is a Tiled map with four layers: Background, Decoration, Objects, and Foreground.
  5. Edit visually in Tiled using the standard tile brush, selection, and object tools. All map properties (music, background, scroll flags, level name) are visible in the Map Properties panel. Each object's type and motion parameters are visible in the Object Properties panel.
  6. Save with File → Save. Tiled calls sblv.js which writes the edited data back to the exact same binary layout: header, foreground layer at 0x364, decoration layer at 0x5184, object array at 0x9FA4. The file is ready to load in the game immediately.

What tiled-blupi Does NOT Do

  • Does not include the game itself — you need Speedy Blupi or Speedy Blupi II installed separately.
  • Does not include a standalone editor — it requires the Tiled application.
  • Does not support every .blp file in the DATA folder — only level files (WORLD###.BLP and u###-###.blp). Other .blp files are not level files and will error.
  • Does not fully decode the BLP format — 804 bytes of the header and ~512 bytes of trailing data are unknown and currently zeroed on save. Unknown object fields are preserved verbatim.
  • Does not include tile extraction tools — the PNG images are pre-extracted and static.
  • Does not support game versions other than Speedy Blupi and Speedy Blupi II.
