Frequently Asked Questions

Answers to the most common questions about tiled-blupi.

General

What is tiled-blupi?

tiled-blupi is a Tiled map editor extension and tileset pack for editing Speedy Blupi and Speedy Blupi II level files (.blp format). It lets you open, edit, and save levels from these games inside the free Tiled map editor. See Overview for details.

Is tiled-blupi an official Blupi tool?

No. It is an independent, community-created project hosted on GitHub at github.com/openeggbert/tiled-blupi. It is not affiliated with Epsitec SA or the original developers of the Speedy Blupi games.

Do I need to pay for anything?

tiled-blupi itself is free and open-source. However:

  • Tiled is free (open-source, available at mapeditor.org; a paid itch.io version also exists).
  • Speedy Blupi / Speedy Blupi II are commercial games. You need to own the game to have the level files.

Which operating systems are supported?

tiled-blupi itself is platform-neutral (it is just files to copy). Tiled runs on Windows, macOS, and Linux. The Speedy Blupi games are Windows applications. On Linux/macOS you can run the games under Wine and edit levels with Tiled natively.

Installation

Where exactly do I copy the tiled folder?

Copy the entire tiled/ folder (from Speedy Blupi/ or Speedy Blupi II/ in the repository) into the root of the game's installation directory — the same folder that contains the game executable and the DATA/ subfolder. See Installation for the complete directory layout.

Can I use tiled-blupi without the game installed?

Partially. You can open and edit levels if you have the .blp level files. However, the background image layer will not show (it requires the game's IMAGE16/ or IMAGE08/ folder). You can still edit tiles and objects without the background.

Do I need to install tiled-blupi separately for each game?

Yes. The SB1 and SB2 implementations are independent. Install Speedy Blupi/tiled/ into the SB1 game directory and Speedy Blupi II/tiled/ into the SB2 game directory.

Editing Levels

How do I add a new object to a level?

  1. Select the Objects layer.
  2. In the Tilesets panel, switch to the Object Types tileset.
  3. Select the Insert Tile Object tool.
  4. Click the canvas to place the object.
  5. In the Properties panel, set the type property to the desired ObjectTypes enum value.

How many objects can a level have?

A maximum of 200 objects per level. This is a hard limit of the BLP format. If you add more in Tiled, only the first 200 will be saved. The extension does not warn you.

Can I change the level's background image?

Yes. Change the background map property value. The new value is written to the BLP file when you save. However, Tiled does not update the displayed background image until you close and reopen the level. You need to know the valid background index values for your game; inspect retail levels to find them.

Can I resize the level (make it larger or smaller than 100×100)?

No. The BLP format has a fixed 100×100 tile grid. The level size is always 100 columns × 100 rows, regardless of how much of the grid you actually fill with tiles. You cannot change this from Tiled.

Can I create a level from scratch in Tiled?

Not directly. The extension does not support Tiled's "New Map" function for creating a new BLP file. Instead, copy and rename an existing level file (e.g., WORLD001.BLP) and open that. Then replace all the content.

The decoration tiles look offset in Tiled — is that normal?

Yes. The explo (decoration) tileset has a tile offset of y=64 pixels in its TSX file. This means decoration tiles appear 64 pixels (one tile) lower in Tiled than their grid position. This is intentional — it matches how the game renders these tiles. When placing decoration tiles, account for this by placing them one row above where you want them to appear visually.

Can I use SB2 objects in SB1 levels or vice versa?

Technically you can set the type property to a sequel-only object type in an SB1 level, but the SB1 extension has no write case for those types, so the resulting BLP type ID will be undefined or incorrect. The game will likely ignore or crash on such objects. Stick to types supported by the game you are targeting.

File Format

What is the BLP format?

A proprietary binary level format used by Speedy Blupi and Speedy Blupi II. Files are exactly 50,468 bytes with a fixed 100×100 tile grid stored as column-major uint16 arrays, and an object array of up to 200 entries. See BLP Format for the full specification.

Are SB1 and SB2 level files interchangeable?

They use identical binary structure. The main difference is minor_version (2 for SB1, 3 for SB2). Loading an SB2 level in SB1 may work for tiles, but SB2-only objects will not function. The safe approach is to keep SB1 and SB2 levels separate.

Technical

Can I look at the source code of sblv.js?

Yes. The file is at tiled/extensions/sblv.js in the repository. It is plain JavaScript with no build step. You can open it in any text editor. See sblv.js in Depth for a guided walkthrough.

Why does saving zero out some fields?

The extension has not decoded all bytes of the BLP format. For the 804-byte unknown header region (0x40–0x363) and the trailing data, the extension writes zeros because it does not know what to write. This is a known limitation — see Known Limitations.

How do I report a bug or suggest a feature?

Open an issue on the GitHub repository. Include the Tiled version, the game version, a description of the problem, and if possible the level file that caused it.
