Supported Games

tiled-blupi supports two games: Speedy Blupi and Speedy Blupi II. Each has its own set of files in the repository, its own Tiled project configuration, and its own extension registration. This page compares the two games from a tiled-blupi perspective.

Which Format to Use

When opening a .blp file in Tiled, you must choose the correct format:

  • Files from the Speedy Blupi game's DATA/ folder → choose Speedy Blupi level
  • Files from the Speedy Blupi II game's DATA/ folder → choose Speedy Blupi 2 level

The format determines which sblv.js implementation is used for reading/writing. Using the wrong format on a file may produce garbled output or errors. The most reliable indicator is minor_version: SB1 files have 2, SB2 files have 3.

Common BLP Structure

Both games use the identical BLP binary layout:

  • Same file size: 50,468 bytes
  • Same byte offsets for all sections (header, foreground layer, decoration layer, object array)
  • Same tile storage formula: column-major uint16
  • Same object struct: 48 bytes per object, same field offsets
  • Same player start BLP type IDs: 200–203

The differences are entirely in the content: more tiles per tileset, more object types, and a different minor_version value.

These types are listed in the SB1 project file's ObjectTypes enum (marked with "(II)") but the SB1 sblv.js has no write cases for them. Using these types in an SB1 level will write incorrect or undefined BLP type IDs.

Installing Both

You can have both games set up simultaneously. Install tiled-blupi into each game directory separately. You can then switch between games in Tiled by opening the appropriate project file (SB1 or SB2) via File → Recent Projects.

When the SB1 project is active, only SB1-formatted files work correctly. When the SB2 project is active, only SB2-formatted files work correctly. You cannot edit both games' levels simultaneously in the same Tiled window.
