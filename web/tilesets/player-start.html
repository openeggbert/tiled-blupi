Player Start Tileset

A 4-tile tileset used to visually represent the four player spawn positions in the Objects layer.

Properties

PropertyValue
TSX filenametilesets/Player Start.tsx
Tile count4 (identical in SB1 and SB2)
Tile size64 × 64 pixels
Image directorytilesets/Player Start/
Used forPlayer spawn points in the Objects layer
BLP type IDs200 (P1), 201 (P2), 202 (P3), 203 (P4)

Tile Details

Tile IDBLP Type IDRepresentshflipClass
0200Player 1 startNoBlupi
1201Player 2 startNoBlupi
2202Player 3 startYesBlupi
3203Player 4 startYesBlupi

Tiles 2 and 3 have horizontal flip enabled in the TSX. This means player 3 and 4 spawn markers appear as horizontally mirrored versions of player 1 and 2 markers in Tiled.

All 4 tiles have class Blupi set in the TSX, which may affect how Tiled categorizes or displays them.

TSX Excerpt

<tileset name="Player Start" tilewidth="64" tileheight="64" tilecount="4" columns="0">
 <tile id="0" class="Blupi">
  <image source="Player Start/0.png" width="64" height="64"/>
 </tile>
 <tile id="1" class="Blupi">
  <image source="Player Start/1.png" width="64" height="64"/>
 </tile>
 <tile id="2" class="Blupi">
  <properties><property name="hflip" type="bool" value="true"/></properties>
  <image source="Player Start/2.png" width="64" height="64"/>
 </tile>
 <tile id="3" class="Blupi">
  <properties><property name="hflip" type="bool" value="true"/></properties>
  <image source="Player Start/3.png" width="64" height="64"/>
 </tile>
</tileset>

How sblv.js Uses This Tileset

When reading a BLP file, the extension checks each object's type field: if the value is 200–203, it creates a Tiled object using tile (type − 200) from the Player Start tileset, at pixel position (x×64, y×64).

On write, for each object in the Objects layer that uses a Player Start tile, the extension writes BLP type ID = (tile_id + 200) to the object struct at +0x00.
