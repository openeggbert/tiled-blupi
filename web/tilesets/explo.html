explo Tileset

The tileset used for the Decoration tile layer. Contains large background elements like plants, rocks, and environmental scenery. Has a critical tile offset of y=64 pixels.

The y=64 Tile Offset — Critical Detail

The explo tileset defines a tile offset in its TSX file:

<tileoffset x="0" y="64"/>

This is the single most important thing to know about this tileset. When Tiled renders an explo tile placed at grid position (x, y), it draws the image at pixel position (x×64, y×64 + 64). This shifts every tile one full tile row downward from where you placed it.

Practical consequence: If you want a decoration to appear visually at grid row 5, you must place the explo tile at grid row 4 in Tiled. Plan decoration placements accordingly.

Why does this offset exist? It matches how the game renders decoration elements — they appear to "sit on" the tile row below their logical position. The offset ensures Tiled's display matches the in-game appearance.

TSX Excerpt

<tileset version="1.10" name="explo" tilewidth="64" tileheight="64"
         tilecount="54" columns="0">
 <tileoffset x="0" y="64"/>
 <grid orientation="orthogonal" width="1" height="1"/>
 <tile id="0">
  <image source="explo/0.png" width="64" height="64"/>
 </tile>
 … (54 entries for SB1, 100 for SB2)
</tileset>
