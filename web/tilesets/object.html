object Tileset

The main tileset used for the Foreground tile layer. Contains all gameplay tiles — ground, platforms, walls, and environmental elements.

Tile Numbering

Tiles are numbered 0 to N-1 (0–245 for SB1, 0–440 for SB2). The tile number is the BLP tile value stored in the foreground layer. Tile number N is stored in the file object/N.png.

A foreground cell with BLP value 0xFFFF (65535) is empty — no tile is rendered.

Usage in sblv.js

When reading a level, the extension reads each uint16 value from the foreground layer section (0x0364) and creates a Tiled tile at the corresponding (x,y) grid position with tile ID = BLP value. On write, the reverse mapping is applied.

// Read: for each cell (x,y):
offset = 0x0364 + (y + 100*x) * 2
tileValue = readUint16LE(offset)   // 0xFFFF = empty, else = tile ID

// Write: for each cell (x,y):
tileID = foregroundLayer.tileAt(x, y)   // Tiled tile ID
writeUint16LE(tileID != -1 ? tileID : 0xFFFF, offset)
