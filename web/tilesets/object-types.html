Object Types Tileset

The tileset used to visually represent all game objects (except player starts) in the Objects layer. Each tile corresponds to one ObjectTypes enum value.

Tile 0 — Endpoint Class

Tile 0 in the Object Types tileset has the class Endpoint set in its TSX definition. This is a special designation — an Endpoint object marks the destination position for a moving object (lift, conveyor, platform). When you add a moving object, you also add an Endpoint object at the destination. The extension reads the Endpoint object's position and uses it as the endpoint property of the main object.

Note
Tile 0 (BLP type ID 1) also represents "Blupi (player)" in the ObjectTypes enum. The Endpoint class is an additional designation layered on top — it is how the extension identifies which objects to treat as endpoints for the linked moving object.
