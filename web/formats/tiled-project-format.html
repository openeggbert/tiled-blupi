Tiled Project Format

The .tiled-project file is a JSON file that tells Tiled where to find extensions, tilesets, and object type definitions for a project. It is the entry point for working with tiled-blupi levels.

File Structure

A minimal annotated example of the speedy-blupi-1.tiled-project file:

{
  "automappingRulesFile": "",
  "commands": [],
  "extensionsPath": "extensions",
  "folders": [
    ".",
    "../level"
  ],
  "objectTypesFile": ""
}

Fields

FieldTypeValue in tiled-blupiPurpose
extensionsPathstring"extensions"Path to the directory containing JS extension scripts, relative to the project file. Tiled loads all .js files from this directory at startup.
foldersarray of strings[".", "../level"]Directories to show in Tiled's Project panel. "." = the project folder itself (containing tilesets/); "../level" = the game's level directory (containing .blp files).
automappingRulesFilestring""Not used by tiled-blupi. Tiled feature for auto-tile rules.
commandsarray[]Not used. Tiled custom commands.
objectTypesFilestring""Not used. Object types are defined in TSX files instead.

extensionsPath Resolution

The path "extensions" is relative to the directory containing the .tiled-project file. If the project file is at:

/Speedy Blupi/speedy-blupi-1/speedy-blupi-1.tiled-project

Then Tiled looks for extensions at:

/Speedy Blupi/speedy-blupi-1/extensions/

And loads sblv.js from that directory. If sblv.js is not found there, no scripted map format is registered and .blp files cannot be opened.

folders Array Resolution

Each entry in folders is relative to the project file location:

EntryResolves To (example)Contents
"."/Speedy Blupi/speedy-blupi-1/Project folder: tilesets/, extensions/
"../level"/Speedy Blupi/level/Level files: blp1001.blp–blp1025.blp

Both entries appear as nodes in the Project panel's tree view, allowing you to browse both the tilesets and the level files from within Tiled without navigating the file system separately.

How Tiled Uses the Project File

  1. Tiled reads the project file on open.
  2. It sets the extensions directory to extensionsPath and loads all JS files found there.
  3. sblv.js (once loaded) calls tiled.registerMapFormat("sblv", sblvMapFormat), telling Tiled that files can be opened and saved in the "sblv" format.
  4. When the user opens a .blp file, Tiled matches the file extension to the registered format and calls sblvMapFormat.read().
  5. The folders in folders are shown in the Project panel for convenient navigation.
Do not add entries to folders that do not exist. If a path in the folders array does not resolve to a real directory (e.g., the project folder was not installed inside the game directory), Tiled will show an error or empty panel for that entry. The extension itself will still load, but the Project panel navigation will not work correctly.
