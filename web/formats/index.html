Formats

The Formats section documents the file format specifications for every file type that tiled-blupi works with. These pages are aimed at developers and technically curious users who want to understand the binary and XML structures involved.

BLP Level Format

Binary specification of the .blp level file: header layout, tile layer storage (column-major), object array structure, and complete byte-level memory map.

Tiled Project Format

JSON structure of the .tiled-project file: extensionsPath, folders array, object-type definitions, and how Tiled uses the project to locate assets.

TSX Tilesets

XML structure of the .tsx tileset files: tile elements, image sources, tile properties, hflip, tileoffset, and how TSX files connect to the game's PNG assets.

PNG Assets

Overview of the PNG image files used by the tilesets: naming conventions, directory layout, per-game asset counts, and usage in TSX files.

Format Relationships

These four file types form a dependency chain:

.tiled-project
  → loads → extensions/sblv.js   (teaches Tiled to open .blp)
  → references → tilesets/*.tsx  (tile definitions)

*.tsx
  → references → ../image/**/*.png  (tile images)

*.blp
  → decoded by → sblv.js
  → displayed with → *.tsx tilesets
