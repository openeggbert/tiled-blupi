PNG Assets

The tile images displayed in Tiled when editing a Speedy Blupi level are individual PNG files stored in the game's image/ directory. These PNGs are part of the original game installation and are not included in the tiled-blupi repository.

Copyright notice: The PNG images in the game's image/ directory are copyrighted by the original game developer. They are not redistributed by the tiled-blupi project. tiled-blupi only provides the TSX tileset definitions (which reference the images) and the extension script. The images must come from a legitimate copy of the game.

Image Directory Layout

The game stores its images in subdirectories under image/. Each subdirectory corresponds to one tileset:

<game dir>/image/
├── element/        ← images for element.tsx (Foreground terrain)
│   ├── t001.png
│   ├── t002.png
│   └── …
├── explo/          ← images for explo.tsx (Decoration)
│   └── …
├── object/         ← images for object.tsx
│   └── …
└── …               ← other asset directories

The exact naming convention and count of files per directory varies between SB1 and SB2.

PNG File Format

The PNG files are standard PNG images (lossless, transparency supported). They are used directly as tile images — one file per tile in the tileset. The columns="0" attribute in the TSX files means Tiled does not combine these into a spritesheet; each tile is loaded from its own individual PNG file.

Replacing or Adding PNG Files

If you want to modify the appearance of tiles, you can replace the corresponding PNG file in the game's image/ directory with a modified version. The replacement PNG must:

  • Be valid PNG format
  • Have the same dimensions as the original (or match the tilewidth/tileheight in the TSX)
  • Have the same file name as the original
Modifying game images will affect the game's appearance, not just Tiled's preview. The same PNG files are used both by Tiled (via TSX references) and by the game engine. Replacing a tile image changes how it looks both in the editor and in-game.
