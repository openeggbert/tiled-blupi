TSX Tilesets Format

TSX (Tiled Set XML) is the file format used by Tiled to define tilesets. Each .tsx file in the tiled-blupi project defines one tileset and references the PNG images that make up its tiles. This page explains the structure of these files and the features they use.

TSX File Structure

A TSX file is well-formed XML. General structure:

<?xml version="1.0" encoding="UTF-8"?>
<tileset version="1.8" tiledversion="1.8.x" name="TILESET_NAME"
         tilewidth="32" tileheight="32" tilecount="N" columns="0">
  <tileoffset x="0" y="64"/>           <!-- optional: only in explo.tsx -->
  <grid orientation="orthogonal" width="1" height="1"/>
  <tile id="0">
    <image width="W" height="H" source="RELATIVE_PATH_TO_PNG"/>
    <objectgroup ...></objectgroup>  <!-- optional collision shapes -->
    <properties>
      <property name="class" value="Endpoint"/>  <!-- optional -->
      <property name="hflip" type="bool" value="true"/>  <!-- optional -->
    </properties>
  </tile>
  <tile id="1"> ... </tile>
  ...
</tileset>

Common Attributes

Attribute / ElementMeaningExample Value
nameTileset name as shown in Tiled"element", "explo"
tilewidth, tileheightWidth and height of each tile in pixels32
tilecountNumber of tiles in the tilesetVaries per tileset
columns="0"Tells Tiled tiles are not in a spritesheet; each tile is a separate image0
tileoffsetPixel offset applied when rendering a tile. Only present in explo.tsx.y="64"
tile idZero-based local tile index within this tilesetid="0", id="1", …
image sourceRelative path to the PNG file for this tile"../image/element/t001.png"

Tile Properties Used by tiled-blupi

Property NameTypeTSX File(s)Purpose in sblv.js
classstringobject-types.tsx (tile 0), player-start.tsx (all tiles)Tile 0 of object-types has class="Endpoint". All player-start tiles have class="Blupi". sblv.js checks these to distinguish Endpoints and player starts from regular objects.
hflipboolplayer-start.tsx (tiles 2 and 3)Marks that the tile is horizontally flipped. Used to indicate a mirrored player start facing direction.

tileoffset in explo.tsx

The explo.tsx tileset contains:

<tileoffset x="0" y="64"/>

This tells Tiled to render every tile from this tileset 64 pixels below (y+64) its grid position. The offset is purely a rendering instruction — it does not affect how the tile is stored in the BLP file. The tile's grid cell is still determined by its logical position in the 100×100 grid.

Image Path Resolution

All source attributes in TSX files are relative to the TSX file's location. Since the TSX files are in speedy-blupi-1/tilesets/, a path like "../image/element/t001.png" resolves to <game dir>/image/element/t001.png. This is why the project must be installed inside the game directory — Tiled must be able to reach the game's image assets via this relative path.

If tile images appear as pink/missing in Tiled: The PNG files could not be found at the relative path. Verify that the project folder is correctly placed inside the game directory, and that the game's image/ directory exists and contains the expected PNG files.
