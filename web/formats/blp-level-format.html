BLP Level Format

The .blp file is the native level format used by Speedy Blupi 1 and Speedy Blupi 2. It is a binary file with a fixed size of exactly 50,468 bytes. All multi-byte values are stored in little-endian byte order. The format stores one 100×100 tile grid for terrain, one for decoration, and an array of up to 200 game objects.

Source of truth: The BLP format was reverse-engineered by reading the sblv.js extension source code. Fields not decoded by the extension are marked "unknown" and are zeroed when the file is round-tripped through tiled-blupi.

Tile Layer Format (Foreground and Decoration)

Each tile layer stores 10,000 uint16 values in column-major order. "Column-major" means all 100 rows of column 0 are stored first, then all 100 rows of column 1, and so on.

Index formula for cell (x, y):
  index = y + 100 * x   (where x is column, y is row, both 0-based)

Byte offset of cell (x, y) in Foreground layer:
  offset = 0x0364 + (y + 100*x) * 2

Byte offset of cell (x, y) in Decoration layer:
  offset = 0x5184 + (y + 100*x) * 2

Tile value encoding:

  • 0xFFFF (65535) — empty cell (no tile)
  • Any other uint16 — zero-based tile index into the corresponding tileset (element for Foreground, explo for Decoration)

Object Array Format (0x9FA4–0xC223)

The object array holds exactly 200 entries. Each entry is 0x30 (48) bytes. Object n starts at 0x9FA4 + n * 0x30. Unused slots contain all zeros.
