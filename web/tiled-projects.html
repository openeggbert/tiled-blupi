Tiled Projects

The .tiled-project files configure the Tiled editor for each supported game. This page explains every field, what it controls, and how it connects the editor to the game.

Project Files

  • Speedy Blupi/tiled/speedyblupi.tiled-project — for Speedy Blupi
  • Speedy Blupi II/tiled/speedyblupi2.tiled-project — for Speedy Blupi II

Both files have identical structure. They are standard Tiled project JSON files. The game-specific differences are in the format name registered by sblv.js and the tile counts in the tilesets.

Opening a Project

Go to File → Open in Tiled and select the .tiled-project file. Tiled will load the project, execute the extension, and configure the editor for the game.

You can also use File → Recent Projects to quickly switch between the SB1 and SB2 projects.

extensionsPath

"extensionsPath": "extensions"

Tells Tiled where to find JavaScript extension files, relative to the project file's location. Resolves to tiled/extensions/. Tiled automatically loads all .js files in this directory when the project opens. In tiled-blupi, this loads sblv.js.

What happens when it loads:

  1. sblv.js is executed by Tiled's JavaScript engine (Qt's QJSEngine, ES5+).
  2. The script calls tiled.registerMapFormat("sblv", sblvMapFormat).
  3. From this point, the format "Speedy Blupi level" appears in Tiled's open/save format selector.

folders

"folders": ["tilesets", "../DATA"]

Lists directories to show in the Tiled Project panel (left sidebar). Both paths are relative to the project file.

  • "tilesets" → resolves to tiled/tilesets/. Shows the tileset files in the panel for easy reference and drag-and-drop.
  • "../DATA" → resolves to DATA/ (one level up from tiled/, which is the game root). Shows the level files directly in the panel, so you can double-click a WORLD###.BLP file to open it without navigating through File → Open.

propertyTypes

Defines custom property types visible in Tiled's Properties panel. The project file defines two types:

Object class

A class type named Object that is applied to game objects in the Objects layer. This class defines all the per-object BLP fields as Tiled properties:

ObjectTypes enum

An enum type named ObjectTypes with 45 named values (0–44). This enum is used as the type for the type property on objects. It allows you to select an object type by name (e.g., "Bomb", "Lift") instead of a raw integer.

In the SB1 project, sequel-only types are suffixed with "(II)" in the enum. In the SB2 project, the same names appear without the "(II)" suffix since they are fully supported.

The integer value of each enum entry (0–44) corresponds to the array index in itemTypesArray in sblv.js, which maps it to the BLP game type ID.
