Object Types Reference

This page provides the complete table of all game object types supported by tiled-blupi, taken directly from the itemTypesArray in the sblv.js extension. Each entry maps a zero-based array index (= Tiled tile index in the object-types tileset) to a BLP game type ID.

How itemTypesArray works: The array position (0, 1, 2, …) equals the tile index in the object-types tileset. The value at that position is the BLP type ID stored in the object struct at offset +0x00. When writing, the extension looks up the object's tileset tile index, reads itemTypesArray[tileIndex], and writes that as the type ID.

SB2-Only Object Types (additional entries in SB2)

SB2's itemTypesArray has 10 additional entries beyond the 34 SB1 entries, for a total of 44 regular object types. The additional types (tile indices 35–44) map to BLP type IDs 34–43. These types do not appear in the SB1 extension and should only be used in SB2 levels.

Player Start Types (both SB1 and SB2)

Player starts are handled separately from the regular object types. They use the player-start tileset and have class=Blupi. The BLP type IDs for player starts are 200–203.

player-start Tile IndexBLP Type IDhflipDescription
0200NoStandard player start
1201NoVariant player start
2202YesMirror of tile 0
3203YesMirror of tile 1
Gap between 43 and 200: BLP type IDs 44–199 are not used by tiled-blupi. They may represent object types not yet reverse-engineered, or they may be unused in the games' level files. If you encounter a type ID in this range in an existing level file, sblv.js does not have an entry for it in itemTypesArray and it will not be correctly displayed.

See also: Object Types in the main docs for gameplay context.
