File Locations Reference

This page is a complete directory of every file and folder in the tiled-blupi setup, what each one does, and where it should be located relative to the game installation.

Repository Structure

The tiled-blupi repository contains separate project trees for each supported game:

tiled-blupi/                        ← repository root
├── README.md
├── .gitignore
├── speedy-blupi-1/                 ← SB1 project tree
│   ├── speedy-blupi-1.tiled-project
│   ├── extensions/
│   │   └── sblv.js                ← SB1 extension (513 lines; registers as "sblv")
│   └── tilesets/
│       ├── blupi000.tsx
│       ├── blupi001.tsx
│       ├── blupi002.tsx
│       ├── blupi003.tsx
│       ├── element.tsx
│       ├── explo.tsx
│       ├── object.tsx
│       ├── object-types.tsx
│       └── player-start.tsx
└── speedy-blupi-2/                 ← SB2 project tree
    ├── speedy-blupi-2.tiled-project
    ├── extensions/
    │   └── sblv.js                ← SB2 extension (552 lines; registers as "sb2lv")
    └── tilesets/
        └── (same set of TSX files as SB1)

Speedy Blupi 2

Same structure as SB1 but under the SB2 game directory, with speedy-blupi-2/ as the project subfolder and level files named blp2001.blp–blp2030.blp.

File That Must NOT Be Edited or Moved

FileReason
speedy-blupi-1.tiled-projectContains relative paths to extensions/ and tilesets/. Moving it breaks all relative references.
extensions/sblv.jsMust be at the path specified by extensionsPath in the project file.
tilesets/*.tsxTSX files reference PNG images by relative path; moving them breaks tileset loading.
Level files (level/blp*.blp)The game loads levels by number from the level/ subdirectory. Moving them means the game cannot find them.

TSX File Path Resolution

Each .tsx file references PNG images with paths relative to the TSX file location. For example, element.tsx might contain:

<image source="../image/element/tile0001.png"/>

This means the PNG is at <game dir>/image/element/tile0001.png, one directory up from where the TSX file is located. This is why the project must be installed inside the game directory — the image assets at image/ must be reachable via the ../image/ relative path from speedy-blupi-1/tilesets/.
