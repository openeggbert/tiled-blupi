Game Differences Reference

This page is a comprehensive side-by-side comparison of the SB1 and SB2 tiled-blupi implementations. When working with both games simultaneously, use this page to understand exactly what is different between them.

Tileset Differences

The tilesets are separate files in each project folder. Visually, they may contain different images (different game assets), but the structure (TSX format, tile count, tileset names) is the same in both games.

Object Type ID Differences

Type IDs 0–33 are shared between SB1 and SB2 (same BLP values, same game behavior). Type IDs 34–43 exist only in SB2:

Working With Both Games

You can have both game projects loaded in Tiled simultaneously. Each project registers its own scripted map format (sblv vs sb2lv), so Tiled can distinguish them. When opening a .blp file, the extension checks the major_version field to confirm it matches the expected version for that project. Opening an SB2 file with the SB1 project loaded will fail the version check.
