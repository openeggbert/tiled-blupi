Tile ID Reference

This page explains how tile identifiers work at every level of the tiled-blupi stack: in the BLP binary file, in Tiled's internal representation, and in the TSX tileset files. Understanding these ID systems is essential for debugging conversion issues.

Three Tile ID Systems

SystemName Used HereTypeRangeZero Means
BLP binary (tile layers)BLP tile valueuint16 little-endian0–65534, or 0xFFFFFirst tile in tileset (index 0)
BLP binary (object type)BLP type IDuint16 little-endian0–203 in practiceObject type 0 (first itemTypesArray entry)
Tiled internalTiled GID (global ID)int1 + tileset_firstgid + local_idNot used (0 = empty cell)

Tile Layers: BLP Tile Value → Tiled GID

In the Foreground and Decoration layers:

  • The BLP file stores a uint16 at each cell. Value 0xFFFF (65535) means the cell is empty.
  • Any other value is a zero-based index into the tileset (element for Foreground, explo for Decoration).
  • Tiled internally uses GIDs (global tile IDs), which are firstgid + local_tile_index. The firstgid for a tileset is determined when the tileset is loaded into the project.

Conversion performed by sblv.js:

// Reading (BLP → Tiled)
if (blp_value === 0xFFFF) {
    tiled_gid = 0;  // empty cell
} else {
    tiled_gid = tileset.firstgid + blp_value;
}

// Writing (Tiled → BLP)
if (tiled_gid === 0) {
    blp_value = 0xFFFF;  // empty
} else {
    blp_value = tiled_gid - tileset.firstgid;
}

Object Layer: BLP Type ID → Tiled Tile

For objects:

  • The BLP file stores a type ID at offset +0x00 in the object struct. This is a game-semantic ID (0–43 for regular objects, 200–203 for player starts).
  • sblv.js converts this to a Tiled tile object by looking up the index in itemTypesArray for regular objects, or the player-start tileset for player starts.
// Reading: BLP type ID → tileset tile index
// For regular objects (type < 200):
tile_index = itemTypesArray.indexOf(blp_type_id);
// (where itemTypesArray[n] = blp_type_id for the tile at index n)

// For player starts (type >= 200):
player_start_tile_index = blp_type_id - 200;  // 0–3

TSX Tile Indices

Inside a .tsx file, each <tile id="N"> element has a zero-based local ID N. This ID directly corresponds to:

  • The BLP tile value (for tile layers) — element.tsx tile id=5 = BLP value 5
  • The itemTypesArray index + 1 (for the object-types tileset) — tile id=0 is the Endpoint tile; tile id=N corresponds to itemTypesArray[N]
