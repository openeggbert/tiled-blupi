Reference

The Reference section provides complete, structured data for every configurable element of tiled-blupi. Unlike the tutorials (which guide you through tasks step-by-step), reference pages are meant to be consulted while working — look up a specific property, object type, or file path and get the precise details.

Map Properties

All custom map properties that the sblv.js extension reads from and writes to the BLP header. Includes BLP file offsets, types, and safe-edit guidance.

Object Properties

All custom properties attached to objects on the Objects layer. Includes struct offsets in the BLP file, types, and valid value ranges.

Object Types

Complete table of all object types, their BLP type IDs, SB1/SB2 availability, tileset tile index, and in-game purpose.

Layers

Full description of each layer: purpose, storage format, BLP offset, tileset, and formula for accessing individual cells.

File Locations

Where every file lives: project files, level files, tilesets, extension scripts, and assets — with OS-specific paths.

Tile ID Reference

How tile IDs work in each layer; the relationship between Tiled tile IDs, tileset indices, and BLP uint16 values.

Game Differences

Side-by-side comparison of SB1 and SB2: object type counts, tileset differences, sblv.js version differences, and level file naming.
