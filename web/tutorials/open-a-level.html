Tutorial 2: Open a Level

In this tutorial you will open Tiled, load the correct project file, open a level file, and understand what you see on screen. After this tutorial you will know the layout of the Tiled interface when working with Speedy Blupi levels.

Prerequisite: Complete Tutorial 1 first. The tiled-blupi project folder must already be in your game directory.

Step 1: Launch Tiled

Start the Tiled map editor. On first launch you may see the "Recent Projects" welcome screen or an empty workspace. Either is fine.

Step 2: Open the Tiled Project File

You must open the .tiled-project file before opening any level. The project file tells Tiled where to find the extensions and tilesets.

  1. In Tiled, choose File → Open File or Project… (keyboard shortcut: Ctrl+O on Windows/Linux, ⌘O on macOS).
  2. Navigate to the game directory where you copied the project folder.
  3. Open the subfolder — e.g., speedy-blupi-1/.
  4. Select the file speedy-blupi-1.tiled-project and click Open.
Do not skip this step. If you open a .blp file before loading the project, Tiled will not know about the sblv scripted format, and it will either reject the file or open it incorrectly as binary data.

After opening the project, the Project panel in Tiled should show the project folder tree. You should also see a notification or no error in the status bar. If Tiled shows a warning about a missing extension, revisit Tutorial 1 to make sure sblv.js is in the right location.

Step 3: Locate the Level Files

The level files (.blp files) are stored in the game's level/ directory, which is outside the tiled-blupi project subfolder. From the game root:

Speedy Blupi/
├── level/
│   ├── blp1001.blp     ← SB1 level 1
│   ├── blp1002.blp     ← SB1 level 2
│   │   …
│   └── blp1025.blp     ← SB1 level 25
└── speedy-blupi-1/     ← project folder

For SB2 the naming scheme is the same but the files are blp2001.blp through blp2030.blp (30 levels).

Step 4: Open a Level File

  1. In Tiled choose File → Open File or Project… again.
  2. Navigate to the game's level/ directory.
  3. Select blp1001.blp (or any other level file) and click Open.

Tiled will call the sblv.js extension to read the file. This may take 1–2 seconds. When it finishes, you will see the map open in the main canvas.

File chooser tip: By default the file chooser may only show .tmx files. Use the file-type dropdown (usually labeled "All Files" or "Tiled Files") and select All Files (*) to make .blp files visible.

Step 5: Understand What You See

When a level opens, Tiled shows the following areas:

Tiled AreaWhat It Shows for a .blp Level
Canvas (center)The 100×100 tile map. Each cell is one game tile (32×32 pixels in the display, though the actual grid size may vary by tileset).
Layers panel (top-right by default)Four layers: Background, Foreground, Decoration, Objects. The extension creates all four when reading a .blp file.
Tilesets panel (bottom-right)All tilesets referenced in the project: element, explo, object, player-start, object-types, and blupi000/blupi001/blupi002/blupi003.
Properties panel (usually bottom-left)The map's custom properties (background, sounds, etc.) when no tile or object is selected. When an object is selected, its properties appear here instead.
ToolbarPainting tools: Stamp Brush (B), Eraser (E), Terrain Brush (T), Fill (F), Select (S, R).

Step 6: Check That All Layers Are Present

Click the Layers panel. You should see exactly four layers listed from top to bottom:

  1. Objects — the object layer containing game entities
  2. Decoration — decorative tile layer (explo tileset)
  3. Foreground — main terrain tile layer (element tileset)
  4. Background — a solid color or image layer (not editable as tiles)
If layers are missing: The extension did not run correctly. Check that the project is open (Step 2) and that sblv.js is in extensions/. Restart Tiled after fixing the problem, then try opening the level again.

Step 7: Navigate the Canvas

Use these Tiled navigation controls to move around the 100×100 map:

ActionHow
PanMiddle-mouse drag, or hold Space and drag
Zoom in/outMouse wheel, or Ctrl++ / Ctrl+-
Fit map in windowCtrl+Shift+H
Jump to tile (0,0)Press Home
Done! You have successfully opened a level. Next: Tutorial 3: Edit Map Properties.
