Tutorial 4: Edit Foreground Tiles

The Foreground layer is the main terrain layer — the ground, walls, platforms, and solid blocks that the player walks on and interacts with. In this tutorial you will learn how to select and paint tiles on this layer.

Tileset used: The Foreground layer uses the element tileset. Make sure this is the active tileset in the Tilesets panel before painting.

Step 1: Select the Foreground Layer

  1. In the Layers panel, click the row labeled Foreground to make it the active layer. The selected layer is usually highlighted in blue.
  2. Confirm by looking at the status bar at the bottom of the Tiled window — it should say the active layer name.
Critical: If you paint without selecting the correct layer, you will place tiles on the wrong layer. This is the most common beginner mistake. Always check the active layer before painting. See Tutorial 10.

Step 2: Select the Element Tileset

  1. In the Tilesets panel (usually bottom-right), click the tab or dropdown for element.
  2. The tileset panel will show all available terrain tiles as a grid of small images.

Step 3: Choose a Tile to Paint

  1. Click a tile in the Tilesets panel to select it as your "stamp". The selected tile gets a blue outline.
  2. You can also select a rectangular group of tiles by clicking and dragging across multiple tiles. This stamps a multi-tile pattern.

Step 4: Paint Tiles With the Stamp Brush

  1. Press B (or click the Stamp Brush icon in the toolbar) to activate the Stamp Brush tool.
  2. Click on any cell in the canvas to paint the selected tile(s) at that position.
  3. Click and drag to paint multiple cells in one stroke.

The stamp brush places exactly the tile you selected from the tileset. For single tiles, one click places one tile. For multi-tile selections, the entire selection is placed as a block.

Step 5: Erase Tiles

To remove a tile and leave the cell empty (which corresponds to 0xFFFF in the BLP file):

  1. Press E or click the Eraser tool in the toolbar.
  2. Click or drag over the tiles you want to erase.
What "empty" means in BLP: An empty cell in the Foreground layer is stored as tile value 0xFFFF (65535) in the binary file. When sblv.js writes the file, it converts Tiled's "no tile" to 0xFFFF automatically.

Step 6: Use the Fill Tool for Large Areas

If you need to fill a large area with the same tile:

  1. Select the tile you want from the Tilesets panel.
  2. Press F or click the Fill (Bucket) tool.
  3. Click anywhere in a contiguous region of the same tile on the canvas. Tiled flood-fills the region.
Be careful with Fill: Flood fill on the Foreground layer can replace large areas unexpectedly if you click in the wrong spot. Use Ctrl+Z (Undo) immediately if this happens.

Step 7: Use the Terrain Brush (Optional)

Tiled's Terrain Brush (press T) can automatically select the correct edge, corner, and center tiles when you paint terrain. This works if the element.tsx tileset has terrain definitions configured. If terrain definitions are not set up, the tool falls back to the stamp brush behavior.

Step 8: Verify the 100×100 Boundary

The Foreground layer is exactly 100 columns wide and 100 rows tall (10,000 cells total). Tiled enforces this boundary — you cannot paint outside the map. If you try to resize the map, do not do so: the BLP format requires exactly 100×100.

Never resize the map. The BLP format hard-codes a 100×100 grid. If you use Tiled's "Resize Map" feature, the file will be corrupted when saved. The map size is always exactly 100×100.

Step 9: Undo / Redo

ActionShortcut
Undo last changeCtrl+Z
Redo undone changeCtrl+Y or Ctrl+Shift+Z

Tips for Effective Foreground Editing

  • Use View → Snap to Grid to keep tiles aligned.
  • Use View → Show Grid (Ctrl+G) to see cell boundaries.
  • Zoom in (Ctrl++) to see individual tiles more clearly when placing small details.
  • Zoom out (Ctrl+-) for an overview of the full 100×100 level.
Done! You can now paint, erase, and fill tiles on the Foreground layer. Next: Tutorial 5: Edit the Decoration Layer.
