Tutorial 3: Edit Map Properties

Every Speedy Blupi level stores several per-level settings in the header section of the .blp file. In Tiled these are exposed as custom map properties. This tutorial shows you how to view and change them.

Prerequisite: Complete Tutorial 2. A level must be open in Tiled.

Step 1: Open the Map Properties Panel

To view the map-level custom properties:

  1. Make sure no tile, object, or layer is selected. Click on an empty area of the canvas outside the map, or press Escape.
  2. The Properties panel (usually at the bottom-left or bottom-right, depending on your Tiled layout) should now show the map properties. If the panel is not visible, go to View → Views and Toolbars → Properties to show it.
  3. Alternatively, use Map → Map Properties… from the menu bar to open a dedicated Properties dialog.

Step 2: Identify the Custom Properties

The Properties panel shows a list of custom properties that the sblv.js extension reads from and writes to the BLP file's header. The properties you will see are:

Property NameTypeBLP OffsetDescription
major_versionint0x0000File format major version. For SB1 this is 1; for SB2 it is 2. Do not change this.
minor_versionint0x0002File format minor version. Default 2 for SB1, 3 for SB2. Do not change this.
backgroundint0x0010 (approx.)Index of the background image displayed behind the level.
musicintvariesIndex of the background music track played during this level.
ambianceintvariesIndex of the ambient sound layer (wind, cave drip, etc.).
Valid index ranges are not documented. The exact valid range of values for background, music, and ambiance is not yet known. Using out-of-range values may cause the game to crash or display a blank background. If unsure, copy the value from another level file and only make small changes.

Step 3: Change a Property Value

To change a property (e.g. the background):

  1. Click on the property row in the Properties panel to select it.
  2. Double-click the value cell, or press F2, to enter edit mode.
  3. Type the new integer value and press Enter to confirm.
  4. The change is reflected immediately in Tiled. It will be written to the .blp file when you save (see Tutorial 9).

Step 4: Look at a Reference Level for Valid Values

The safest way to find valid property values is to open several existing levels and note the values used by the game's designers:

  1. Open blp1001.blp and record its background, music, and ambiance values.
  2. Open blp1005.blp and do the same.
  3. Compare — this gives you an idea of the range in use.

Because the game has 25 (SB1) or 30 (SB2) levels, you can survey all of them to build a complete picture of what values appear.

Step 5: Save and Test

After changing a property:

  1. Save the file with Ctrl+S.
  2. Launch Speedy Blupi and load that level number.
  3. Verify the background or music changed as expected.
Done! You know how to view and change per-level settings. Next: Tutorial 4: Edit Foreground Tiles.
