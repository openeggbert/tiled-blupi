Tutorial 1: Install Into Game Folder

In this tutorial you will copy the tiled-blupi project folder into your Speedy Blupi game directory so that Tiled can find the level files, tilesets, and extension script all in one place. This is required before you can open any level.

Time needed: 5–10 minutes. Difficulty: Easy. Requires: tiled-blupi repository (cloned or downloaded), at least one Speedy Blupi game installed.

Step 1: Find Your Speedy Blupi Game Directory

The game directory is wherever Speedy Blupi was installed. The exact path depends on your operating system and how the game was installed.

OSTypical Default PathNotes
Windows (GOG)C:\GOG Games\Speedy BlupiGOG Galaxy puts games here by default
Windows (other)C:\Program Files\Speedy BlupiMay vary; check your installer
Linux (native)/usr/local/games/blupiIf installed system-wide from package
Linux (home)~/games/blupi or ~/.local/share/blupiIf installed per-user
macOS/Applications/Speedy Blupi.app/Contents/ResourcesInside the .app bundle
How to confirm you have the right directory: Look for a file called game.blp (or similar) and a subfolder called image/ or sound/. If you see these, you are in the correct place.

Step 2: Locate the tiled-blupi Folder to Copy

Inside the tiled-blupi repository, there are two project folders — one for each game:

tiled-blupi/
├── speedy-blupi-1/          ← copy this for SB1
│   ├── speedy-blupi-1.tiled-project
│   ├── extensions/
│   │   └── sblv.js
│   ├── tilesets/
│   └── levels/              ← placeholder; actual levels are in game dir
└── speedy-blupi-2/          ← copy this for SB2
    ├── speedy-blupi-2.tiled-project
    ├── extensions/
    │   └── sblv.js
    └── tilesets/

Copy the entire speedy-blupi-1/ folder (for SB1) or speedy-blupi-2/ (for SB2), or copy both if you have both games.

Step 3: Copy the Folder Into the Game Directory

Place the copied folder directly inside your Speedy Blupi game directory. After copying, the structure should look like this (SB1 example):

Speedy Blupi/                 ← your game installation directory
├── game.blp                  ← game data (pre-existing)
├── image/                    ← game images (pre-existing)
├── sound/                    ← game sounds (pre-existing)
├── level/                    ← level files: blp1001.blp … blp1025.blp
└── speedy-blupi-1/           ← you just copied this in
    ├── speedy-blupi-1.tiled-project
    ├── extensions/
    │   └── sblv.js
    └── tilesets/
        ├── element.tsx
        ├── explo.tsx
        └── …
Do not rename the folder. The .tiled-project file uses relative paths to find extensions/ and tilesets/. Renaming the project folder will break these paths and Tiled will not load the extension or tilesets.

Step 4: Verify the Copy

After copying, verify the following files exist:

FileWhat It Means If Missing
speedy-blupi-1/speedy-blupi-1.tiled-projectTiled will have no project to open
speedy-blupi-1/extensions/sblv.jsTiled cannot read or write .blp files
speedy-blupi-1/tilesets/element.tsxForeground layer tiles will show as missing
speedy-blupi-1/tilesets/object.tsxObject layer tiles will show as missing
speedy-blupi-1/tilesets/player-start.tsxPlayer start tiles will be unavailable

Step 5: (Optional) Installing SB2 at the Same Time

If you have both games installed, you can copy both project folders. The SB2 folder goes into the SB2 game directory:

Speedy Blupi 2/               ← SB2 game directory
└── speedy-blupi-2/           ← copy this one for SB2
    ├── speedy-blupi-2.tiled-project
    ├── extensions/
    │   └── sblv.js
    └── tilesets/

Each game's project folder is independent. Tiled allows you to have multiple projects open simultaneously, so you can work on SB1 and SB2 levels at the same time once both are installed.

Troubleshooting This Step

ProblemLikely CauseFix
Cannot paste — permission deniedGame installed in a protected directoryCopy with administrator/sudo privileges, or reinstall the game to a user-writable location
Files were copied but tilesets still show as missing in TiledTiled project file is not in the right relative positionMake sure the speedy-blupi-1/ folder is directly inside the game root, not inside a subfolder of it
sblv.js extension does not load in TiledTiled cannot find the extensions/ directoryCheck that speedy-blupi-1.tiled-project has "extensionsPath": "extensions" and that the JS file is at extensions/sblv.js
