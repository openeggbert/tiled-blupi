Tutorials

Step-by-step guides for every common task in tiled-blupi. Each tutorial builds on the previous one. If you are new, start at Tutorial 1 and work through them in order. Experienced users can jump to any tutorial directly.

Prerequisites: Before starting Tutorial 1, make sure you have Tiled map editor installed and at least one Speedy Blupi game installed on your computer. See the Installation page if you have not set up tiled-blupi yet.

Tutorial Path

The tutorials below follow a logical sequence. Tutorials 1–3 cover setup; Tutorials 4–8 cover editing each type of content; Tutorial 9 covers saving; Tutorial 10 covers mistakes to avoid.

1. Install Into Game Folder

Copy the tiled-blupi project files into your Speedy Blupi game directory so Tiled can find all tilesets, extension scripts, and level files in one place.

2. Open a Level

Open Tiled, load the correct .tiled-project file, and open one of the 25 or 30 built-in level files. Understand what you see on screen.

3. Edit Map Properties

Change the level's background, ambient sound track, and other per-level settings using the Map Properties panel.

4. Edit Foreground Tiles

Paint, erase, and replace tiles on the main terrain layer using Tiled's stamp brush, terrain brush, and eraser tools.

5. Edit the Decoration Layer

Add visual decorations — trees, flowers, signs — to the decoration layer without changing the terrain.

6. Edit Objects

Add, move, and configure game objects such as enemies, collectables, and hazards on the Objects layer.

7. Set Player Start Position

Place or move the player start object, understand the difference between the four player-start tile variants, and verify the position will work in-game.

8. Create a Moving Object

Configure an object to move between two points using the endpoint, timing, and wait-time object properties.

9. Save a Level

Save your edits back to the .blp file and verify the file size is exactly 50,468 bytes to confirm the write succeeded.

10. Avoid Common Mistakes

A reference list of the most common errors — wrong project file, wrong layer, tile count exceeded — and how to avoid each one.
