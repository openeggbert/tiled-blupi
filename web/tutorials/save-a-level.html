Tutorial 9: Save a Level

Saving a level in tiled-blupi means writing Tiled's in-memory map data back to the .blp binary file, replacing the original. The sblv.js extension handles the conversion from Tiled's format to BLP binary. This tutorial explains how to save and how to verify the save succeeded.

Saving overwrites the original file. Tiled does not create backups automatically. Before saving significant changes for the first time, make a manual backup copy of the .blp file. Copy it to a different folder or rename it (e.g., blp1001.blp.bak).

Step 1: Back Up the Original File (First Time)

  1. In your file manager, navigate to the game's level/ directory.
  2. Copy blp1001.blp (or whichever file you are editing) to a safe location, such as a backup/ folder or your desktop.
  3. Return to Tiled.

Step 2: Save With Ctrl+S

  1. In Tiled, press Ctrl+S (Windows/Linux) or ⌘S (macOS).
  2. Tiled calls the sblv.js extension's write() function.
  3. The extension serializes all layers and map properties back into the BLP binary format and writes to the file.
  4. Tiled removes the asterisk (*) from the title bar tab, indicating the file is saved.
What the extension writes:
  • Header fields (major_version, minor_version, background, music, ambiance, …)
  • A zeroed region for unknown header fields
  • Foreground layer: 10,000 uint16 values (column-major order)
  • Decoration layer: 10,000 uint16 values (column-major order)
  • Object array: exactly 200 object structs of 0x30 bytes each
  • Trailing bytes to fill the file to exactly 50,468 bytes

Step 3: Verify the File Size

A correctly written BLP file is always exactly 50,468 bytes. Verify this after saving:

  1. Open a terminal or file manager.
  2. Navigate to the game's level/ directory.
  3. Check the file size of the saved file:
# Linux / macOS
ls -l blp1001.blp
# Expected: -rw-r--r-- 1 user group 50468 Jun 13 10:00 blp1001.blp

# Windows (PowerShell)
(Get-Item blp1001.blp).Length
# Expected: 50468
If the file size is wrong: Do NOT load the corrupted file in the game. Restore from your backup. Then investigate what went wrong — common causes are the map being resized (not 100×100) or a scripting error in sblv.js. Check Tiled's JavaScript console for error messages (View → Script Console).

Step 4: Save As (to a Different File)

To save to a different file (e.g., to create a new custom level):

  1. Use File → Save As… (Ctrl+Shift+S).
  2. Navigate to the desired location and enter a new file name.
  3. Click Save.

The new file will be written with the BLP format by sblv.js, just like a regular save. Note that the game only loads levels with the expected file names (blp1001.blp–blp1025.blp for SB1). Saving under a different name creates a file the game will not automatically find.

Step 5: Test in the Game

  1. Launch Speedy Blupi.
  2. Select the level number corresponding to the file you edited.
  3. Play through the level and verify your edits appear correctly.
