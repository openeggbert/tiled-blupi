Tutorial 6: Edit Objects

The Objects layer holds game entities: enemies, collectables, hazards, NPCs, and the player start position. This tutorial covers adding new objects, moving existing ones, changing their type, and setting basic properties.

Object limit: The BLP format stores exactly 200 object slots. If you add more than 200 objects (including player starts), the sblv.js extension will silently write only the first 200. There is no error message. Always count your objects before saving.

Step 1: Select the Objects Layer

  1. In the Layers panel, click the row labeled Objects.
  2. Switch to the Select Objects tool (press S) or the Insert Tile Object tool.

Step 2: Understand Object Representation in Tiled

In tiled-blupi, game objects are represented as Tiled tile objects — objects that have a tile image from the object-types tileset. Each tile in that tileset corresponds to one object type from the ObjectTypes enum in sblv.js.

TilesetUsed For
object-typesAll regular game objects (enemies, items, etc.) — one tile per type
player-startPlayer start positions — 4 tile variants (facing direction, mirror)

Step 3: Add a New Object

  1. In the Tilesets panel, switch to the object-types tileset.
  2. Click the tile corresponding to the object type you want to place. (Each tile represents one game object type. Tile 0 = first object type in the enum, tile 1 = second, etc.)
  3. In the toolbar, click the Insert Tile Object button (or press T in insert mode).
  4. Click on the canvas at the position where you want the object. A tile object is placed at that grid position.
Tile 0 special case: Tile 0 in the object-types tileset has the class Endpoint. It represents the motion endpoint for moving objects. You should not place this independently — it is set via the endpoint properties on a moving object (see Tutorial 8).

Step 4: Move an Object

  1. Press S to activate the Select Objects tool.
  2. Click the object on the canvas to select it (it gets a selection outline).
  3. Drag it to the new position, or use the arrow keys to nudge it by one grid cell.

Object positions are stored in the BLP file as grid coordinates (x and y, each 0–99). When you move an object in Tiled, its position is converted to grid coordinates by Math.floor(pixel_position / tile_size) when saving.

Step 5: Delete an Object

  1. Select the object with the Select tool.
  2. Press Delete or Backspace.

The object is removed from Tiled's object layer. When saved, the corresponding slot in the BLP object array will be zeroed out.

Step 6: Inspect Object Properties

  1. Select an object with the Select tool.
  2. The Properties panel updates to show this object's custom properties.

Standard properties visible on objects:

PropertyMeaning
xHorizontal grid position (0–99). Set by Tiled automatically from object position.
yVertical grid position (0–99). Set by Tiled automatically.
typeGame type ID (integer). The BLP type number. Read from the tileset's class/property.
endpoint_xX coordinate of motion endpoint (for moving objects). 0 if not moving.
endpoint_yY coordinate of motion endpoint. 0 if not moving.
a_to_b_timeTicks to travel from start (A) to endpoint (B).
b_to_a_timeTicks to travel from B back to A.
a_waitTicks to wait at position A before moving.
b_waitTicks to wait at position B before moving back.

Step 7: Check Object Count

To count the number of objects currently on the map:

  1. Open Edit → Select All while the Objects layer is active.
  2. The status bar should show the count of selected objects.
  3. Alternatively, open Map → Map Properties — some Tiled versions show object count in the info area.
Done! You can now add, move, and inspect objects. Next: Tutorial 7: Set Player Start Position.
