Editing Workflow

A recommended end-to-end workflow for editing Speedy Blupi levels with tiled-blupi, from opening a level to testing it in-game.

Before You Start

  1. Back up your levels. Copy the original DATA/ folder to a safe location before making any edits. Saving overwrites the original file with no undo.
  2. Open the project first. Always open the .tiled-project file before opening any .blp level files. This ensures the extension is loaded.
  3. Close the game. Editing a level that the game currently has open may cause issues. Close the game before saving edited levels.

Typical Session

  1. Launch Tiled.
  2. Open the Tiled project: File → Open → tiled/speedyblupi.tiled-project (or SB2 equivalent).
  3. In the Project panel, navigate to the DATA folder.
  4. Double-click a level file to open it.
  5. In the format selector, choose the correct format (Speedy Blupi level or Speedy Blupi 2 level).
  6. Make your edits (tiles, objects, properties).
  7. Save: File → Save (Ctrl+S).
  8. Switch to the game and test the level.
  9. Return to Tiled and repeat from step 6 as needed.

Editing Foreground Tiles

  1. Click Foreground in the Layers panel to make it active.
  2. In the Tilesets panel, click the object tileset tab.
  3. Click a tile to select it (or click-drag for a multi-tile stamp).
  4. Use the Stamp Brush (B) to paint on the canvas. Hold Shift to paint lines.
  5. Use the Eraser (E) to remove tiles (creates empty cells in BLP: 0xFFFF).
  6. Use the Bucket Fill (F) to flood-fill a region.
  7. Use Ctrl+Z to undo and Ctrl+Y to redo (within the current session only).

Editing Decoration Tiles

  1. Click Decoration in the Layers panel.
  2. In the Tilesets panel, select the explo tileset.
  3. Place tiles as for the foreground layer.
  4. Remember that decoration tiles appear 64 pixels (1 tile row) lower than their grid position in Tiled due to the explo tileset's tile offset. Plan placements accordingly.

Editing Objects

  1. Click Objects in the Layers panel.
  2. Use the Select Objects tool (S) to select an existing object.
  3. In the Properties panel, view and edit the object's properties.
  4. To move an object, drag it. Use Snap to Grid to keep alignment.
  5. To add an object:
    • In the Tilesets panel, select the Object Types tileset.
    • Select the Insert Tile Object tool.
    • Click on the canvas to place.
    • Set the type property to the desired ObjectTypes enum value.
  6. To delete: select the object and press Delete.

Editing Map Properties

  1. Click on an empty part of the canvas to deselect all objects.
  2. The Properties panel shows the map's custom properties (major_version, minor_version, music, etc.).
  3. Click a value to edit it. Press Enter to confirm.
  4. Changes are written to the BLP header on save.

Saving

  1. File → Save (Ctrl+S): Overwrites the original .blp file. No confirmation dialog.
  2. File → Save As: Saves to a new path. Tiled will ask for the format again.
No automatic backup
Saving always overwrites the file. Keep manual backups of your original level files before making any changes.

Testing in the Game

  1. Make sure the game is closed before saving from Tiled.
  2. After saving, launch the game and navigate to the edited level.
  3. Play through the level to verify your changes work as expected.
  4. Return to Tiled to make additional adjustments as needed.

Tips

  • Use View → Show Grid to see the 64-pixel tile grid on the canvas.
  • Use View → Snapping → Snap to Grid to keep objects aligned to tile boundaries.
  • Zoom in (Ctrl+scroll) for detail work; zoom out to see the whole level.
  • Use Edit → Select All followed by copy/paste to duplicate sections of a level.
  • Keep the Layers panel visible to quickly switch between the Foreground, Decoration, and Objects layers.
  • Use the scripting console (View → Views and Toolbars → Console) to check for extension errors after a save.
