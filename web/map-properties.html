Map Properties

tiled-blupi exposes seven fields from the BLP file header as custom map properties in Tiled. This page explains each property in detail — its purpose in-game, its BLP byte offset, valid values, and how the extension handles it on read and write.

✓ Verified from sblv.js and README.md
All offsets and field descriptions are verified from the extension source code and the README.

Accessing Map Properties in Tiled

To view or edit map properties:

  1. Click on an empty area of the Tiled canvas to deselect all objects.
  2. The Properties panel (usually on the left) shows the map's custom properties.
  3. Alternatively, go to Map → Map Properties in the menu.
  4. Click a property value to edit it.
  5. Changes take effect when you save the file — the new values are written to the BLP header.

major_version

AttributeValue
BLP offset0x0000
Size4 bytes
Typeint32 little-endian
In retail levelsAlways 1
Default on writeRead-back from property (no default; will be 1 from previous read)

The major version field identifies the BLP format version. The sblv.js extension checks this on read and refuses to open the file if it is not equal to 1. If you see the error "major_version is not 1", you are trying to open a file that is not a recognized Speedy Blupi level.

Do not change major_version
Changing this to any value other than 1 will make the level unloadable by both the game and the extension.

minor_version

AttributeValue
BLP offset0x0004
Size4 bytes
Typeint32 little-endian
Retail SB1 levels2
Retail SB2 levels3
Default on write (SB1 extension)2 (if property is absent)
Default on write (SB2 extension)3 (if property is absent)

The minor version differentiates SB1 from SB2 levels. Retail SB1 levels use value 2; retail SB2 levels use value 3. On write, the extension uses whatever value is stored in the Tiled map property, defaulting to 2 (SB1) or 3 (SB2) if the property is not set.

? Needs verification
The exact effect of non-standard minor_version values (other than 2 or 3) on game behavior is unknown.

horz_scroll

AttributeValue
BLP offset0x0008
Size4 bytes
Typeint32 little-endian
Common values0 (disabled) or non-zero (enabled)
Default on write0

Controls whether the camera scrolls horizontally. When set to a non-zero value, the camera follows the player left and right as they move. When 0, the camera is fixed horizontally.

For a level that is wider than the visible screen area, you typically want horz_scroll = 1. For a single-screen level, horz_scroll = 0 is appropriate.

vert_scroll

AttributeValue
BLP offset0x000C
Size4 bytes
Typeint32 little-endian
Common values0 (disabled) or non-zero (enabled)
Default on write0

Controls whether the camera scrolls vertically. When set to a non-zero value, the camera follows the player as they move up and down. For multi-story levels, set this to 1.

music

AttributeValue
BLP offset0x0010
Size4 bytes
Typeint32 little-endian
Valid range? Needs verification — depends on game audio files
Default on write0

Selects which music track plays during the level. The index corresponds to an audio track in the game's sound data. To determine which index maps to which track, you would need to inspect the retail levels and compare music values to the tracks that play in-game.

background

AttributeValue
BLP offset0x0014
Size4 bytes
Typeint32 little-endian
Valid range? Needs verification — depends on IMAGE16/ files
Default on write0

Selects the background image displayed behind the level. The value is an index that determines which image file is loaded from the game's IMAGE16/ (or IMAGE08/) directory. The extension also reads this value to display the background in Tiled — but changing it in Tiled does not refresh the displayed background until the level is closed and reopened.

Tip — finding valid background values
Open several retail levels in Tiled and note the background property values. Compare them to what background appears visually. This lets you build a list of valid index values.

name

AttributeValue
BLP offset0x0018
Size40 bytes
Typenull-terminated ASCII string
Max usable length39 characters (the 40th byte is always null)
Default on writeEmpty string ""

The level's display name. Shown in the game's level select or HUD. Stored as a 40-byte null-terminated ASCII string starting at offset 0x18. Only ASCII characters are supported; do not use Unicode or special characters.

The maximum usable length is 39 characters (the 40th byte must be a null terminator). If you enter more than 39 characters, the extension will truncate on write.
