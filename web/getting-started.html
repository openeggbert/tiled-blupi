Getting Started

A complete beginner's guide to installing tiled-blupi and making your first edit to a Speedy Blupi level. This page covers every step from prerequisites to a saved, game-ready level file.

Prerequisites

Before you begin, make sure you have the following:

RequirementWhere to get itNotes
Tiled map editor mapeditor.org Free, open-source. Download the latest stable release. Tiled must support scripted map formats (version 1.3 or later).
Speedy Blupi or Speedy Blupi II blupi.org The game must be installed. You need the DATA/ folder (level files) and IMAGE16/ or IMAGE08/ folder (background images). tiled-blupi is installed into the game directory.
tiled-blupi repository github.com/openeggbert/tiled-blupi Clone with git clone https://github.com/openeggbert/tiled-blupi.git, or download and extract the ZIP archive from the GitHub Releases or Code menu.

Step 1 — Copy the tiled Folder into Your Game Directory

✓ Verified from README.md
"Simply take the tiled folder for the game you want to edit and place it directly in the game's install folder."

The repository contains one tiled/ folder for each game. You must use the correct one:

  • For Speedy Blupi: use tiled-blupi/Speedy Blupi/tiled/
  • For Speedy Blupi II: use tiled-blupi/Speedy Blupi II/tiled/

Copy the entire tiled folder (the folder itself, not just its contents) into the root of the game's installation directory.

After copying, your game directory should look like this:

C:\Games\Speedy Blupi\          ← example on Windows
├── tiled\                        ← ← ← this is what you just copied
│   ├── speedyblupi.tiled-project
│   ├── extensions\
│   │   └── sblv.js
│   └── tilesets\
│       ├── object.tsx
│       ├── explo.tsx
│       └── …
├── DATA\
│   ├── WORLD001.BLP
│   ├── WORLD002.BLP
│   └── …
├── IMAGE16\
│   └── *.bmp
└── Blupi.exe
Warning — Do not mix the two game folders
The Speedy Blupi/tiled/ folder must only be used with the Speedy Blupi game, and the Speedy Blupi II/tiled/ folder only with Speedy Blupi II. The two implementations register different format IDs and have different object type sets. Mixing them produces incorrect output.

Step 2 — Open the Tiled Project File

Launch Tiled. Then open the project file from the game directory:

  1. In Tiled, go to File → Open.
  2. Navigate to <game directory>/tiled/.
  3. Select speedyblupi.tiled-project (Speedy Blupi) or speedyblupi2.tiled-project (Speedy Blupi II).
  4. Click Open.

When the project loads, Tiled will:

  • Execute sblv.js from the extensions/ subfolder, registering the custom map format.
  • Show the tilesets/ and ../DATA folders in the Project panel (usually on the left).
  • Make the Object class and ObjectTypes enum available in the Properties panel.
Tip — Verify the extension loaded
After opening the project, go to Edit → Preferences → Plugins (or check the Tiled scripting console at View → Views and Toolbars → Console). If there were errors in sblv.js, they appear there. A successful load produces no output; the format becomes available when you try to open a .blp file.

Step 3 — Open a Level File

✓ Verified from README.md
"Levels are found in the DATA folder, named WORLD###.BLP for standard levels, and u###-###.blp for custom levels; there are other files in the folder, but trying to open them will just cause errors."
  1. In Tiled, go to File → Open.
  2. Navigate to <game directory>/DATA/.
  3. Select a file: standard levels are WORLD001.BLP through WORLD###.BLP; custom levels are named u001-001.blp etc.
  4. When Tiled asks for the file format, choose:
    • Speedy Blupi level for SB1 files
    • Speedy Blupi 2 level for SB2 files
  5. Click OK.

Tiled will call sblv.js's read() function, which:

  1. Reads the 7 header fields (version, scroll flags, music, background, name) and sets them as map custom properties.
  2. Reads the 100×100 foreground tile grid from offset 0x364 (column-major uint16 array) and creates a tile layer named Foreground using the object tileset.
  3. Reads the 100×100 decoration tile grid from offset 0x5184 and creates a tile layer named Decoration using the explo tileset.
  4. Reads up to 200 object structs (48 bytes each) from offset 0x9FA4, creates an object layer named Objects, and places a Tiled object for each non-empty slot.
  5. Loads the background image from the game's IMAGE16/ or IMAGE08/ folder and adds it as a locked Background image layer.

Step 4 — Understand the Layers Panel

After opening a level, the Layers panel shows four layers (top to bottom as displayed in Tiled):

Layer NameTypeEditableContents
Foreground Tile Layer Yes The main gameplay tiles — platforms, walls, ground. Uses the object tileset. All 100×100 cells can be edited.
Decoration Tile Layer Yes Large background decorations (plants, rocks, etc.). Uses the explo tileset. Tiles appear 64 pixels lower than their grid position in Tiled due to the explo tileset's tileoffset y=64.
Objects Object Layer Yes Game objects: enemies, collectibles, hazards, moving platforms, and player start positions. Each object has a visual marker tile and editable properties in the Properties panel.
Background Image Layer No (locked) The level's background image loaded from the game's IMAGE16/ or IMAGE08/ folder. Display only — not written to the BLP file.

Step 5 — View and Edit Map Properties

Open Map → Map Properties (or look in the Properties panel when no object is selected) to see the custom map properties read from the BLP header:

PropertyBLP OffsetDescription
major_version0x00Must be 1. Read-only in practice — changing it will prevent the game from loading the level.
minor_version0x04Version sub-field. SB1 retail levels use 2; SB2 retail levels use 3. Defaults to 2/3 on write if not set.
horz_scroll0x08Horizontal scrolling flag. Non-zero enables horizontal camera movement.
vert_scroll0x0CVertical scrolling flag. Non-zero enables vertical camera movement.
music0x10Music track index. Controls which background music plays in the level.
background0x14Background image index. Controls which image is loaded from IMAGE16/IMAGE08. Requires reopening the level in Tiled to see the change.
name0x18Level name (up to 39 characters). Displayed in-game. Stored as a null-terminated 40-byte string.

Step 6 — Make an Edit

Editing Foreground Tiles

  1. Select the Foreground layer in the Layers panel.
  2. Open the Tilesets panel (View → Views and Toolbars → Tilesets) and select the object tileset.
  3. Click a tile in the tileset panel to select it.
  4. Use the Stamp Brush tool (B) to paint tiles on the canvas.
  5. Use the Eraser tool (E) to remove tiles (sets cells to empty / 0xFFFF in BLP).

Editing Objects

  1. Select the Objects layer in the Layers panel.
  2. Use the Select Objects tool (S) to click on an existing object.
  3. The Properties panel shows the object's type and all BLP fields.
  4. To add a new object: use Insert Tile Object, select a tile from the Object Types tileset, and place it on the canvas.
  5. Set the type property to the desired ObjectTypes enum value.

Step 7 — Save the Level

  1. Go to File → Save (or Ctrl+S).
  2. Tiled calls sblv.js's write() function, which serialises the map back to the binary BLP format.
  3. The file is written directly over the original .blp file.
Always back up your level files
Saving overwrites the original file immediately. There is no automatic backup and no undo for saved files. Before editing any retail level, copy the original to a safe location.

After saving, load the game and select your edited level to test your changes.

Quick Troubleshooting

ProblemLikely causeFix
Format not listed when opening .blp Extension did not load Check the Tiled scripting console for errors. Ensure the project file was opened (not just any file). Verify sblv.js is in tiled/extensions/.
Level opens blank / no tiles visible Wrong format chosen, or tile images missing Close and reopen, selecting the correct format. Verify the tilesets/object/ folder contains PNG files.
Objects not visible Objects layer hidden or wrong tileset path Make sure the Objects layer is visible. Verify tilesets/Object Types/ exists with PNG files.
Game crashes after saving Unknown header bytes zeroed Zeroing the unknown header region may affect some levels. Keep originals backed up. This is a known limitation.

See Troubleshooting for a comprehensive list of problems and solutions.
