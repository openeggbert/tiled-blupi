Assets

tiled-blupi includes a large collection of PNG tile images extracted from the Speedy Blupi games. This page documents all asset directories, file counts, naming conventions, and how the assets are used by the extension.

Asset Organization

All tile image assets are stored under tiled/tilesets/. Each tileset has its own subdirectory named after the tileset, containing one PNG file per tile. 

tilesets/
├── object/           ← foreground tile images
│   ├── 0.png
│   ├── 1.png
│   └── … (246 for SB1, 441 for SB2)
├── element/          ← sprite/misc tile images
│   └── … (187 / 289)
├── explo/            ← decoration tile images
│   └── … (54 / 100)
├── blupi000/         ← player 1 animation frames
│   └── … (291 / 336)
├── blupi001/ blupi002/ blupi003/
│   └── … (same counts)
├── Player Start/     ← 4 player spawn marker images
│   ├── 0.png, 1.png, 2.png, 3.png
└── Object Types/     ← object type marker images
    └── 0.png … 33.png (SB1) or 0.png … 43.png (SB2)

Naming Convention

  • Files are named N.png where N is the 0-based tile index.
  • No gaps — files are numbered consecutively from 0.
  • The tile index corresponds directly to the Tiled tile ID and to the BLP tile value in the foreground/decoration layers.

Image Properties

  • All images are 64 × 64 pixels.
  • PNG format with alpha channel (RGBA).
  • Extracted from the game's sprite data.
  • These are static files — they are not generated by the extension at runtime.

Replacing or Updating Assets

To replace a tile image with an improved version, simply replace the corresponding PNG file in the appropriate subdirectory. The filename must remain unchanged (e.g., 42.png). Tiled will use the new image the next time the project or tileset is reloaded.

To add new tiles to an existing tileset, add the next numbered PNG file and update the corresponding TSX file. See Updating Tilesets for the full process.
