Project Structure

A complete annotated map of the tiled-blupi repository, explaining the purpose of every file and directory.

Top-Level Layout

tiled-blupi/
├── README.md
├── Speedy Blupi/
│   └── tiled/
└── Speedy Blupi II/
    └── tiled/

The repository root contains only the README.md file and two game-specific subdirectories. Each subdirectory contains a single tiled/ folder that is designed to be copied into the corresponding game installation directory.

README.md

The primary human-readable documentation for the project. It covers:

  • Installation instructions (copy the tiled folder into the game directory).
  • Level file naming conventions (WORLD###.BLP, u###-###.blp).
  • Description of all four Tiled layers.
  • All map properties with BLP byte offsets.
  • Object properties list.
  • Links to the Tiled editor and Blupi games.

Speedy Blupi/tiled/ (and Speedy Blupi II/tiled/)

The Project File (*.tiled-project)

A JSON file that configures the Tiled editor for this project. Key fields:

  • "extensionsPath": "extensions" — tells Tiled to load all .js files from the extensions/ subdirectory relative to the project file.
  • "folders": ["tilesets", "../DATA"] — shows these two directories in the Project panel. ../DATA is the game's DATA folder (one level up from tiled/).
  • "propertyTypes" — defines the Object class (with all per-object BLP properties) and the ObjectTypes enum (45 values mapping enum names to integer indices).

extensions/sblv.js

The core of the entire project. A single JavaScript file (~500 lines for SB1, ~550 for SB2) that implements a Tiled scripted map format. When Tiled loads the project, it executes this file. The file:

  1. Declares itemTypesArray — a 34-entry (SB1) or 44-entry (SB2) array mapping enum indices to BLP type IDs.
  2. Defines sblvMapFormat — an object with name, extension, read(), and write() methods.
  3. Calls tiled.registerMapFormat("sblv", sblvMapFormat) (or "sb2lv" for SB2) to make the format available in Tiled.

See sblv.js in Depth for a full code walkthrough.

How the Paths Connect

When the game installation contains the tiled/ folder: 

Game/
├── tiled/
│   ├── speedyblupi.tiled-project   → extensionsPath = "extensions"
│   │                                 folders = ["tilesets", "../DATA"]
│   ├── extensions/sblv.js           ← loaded by project file
│   └── tilesets/object.tsx         → source="object/0.png" (relative to tsx)
└── DATA/WORLD001.BLP               ← "../DATA" from tiled-project perspective

All paths in TSX files are relative to the TSX file's own location. All paths in the project file are relative to the project file's location. This means the entire tiled/ folder is self-contained and portable.
