Layer Conversion

How the foreground and decoration tile layers are converted between the BLP binary format (column-major uint16 arrays) and Tiled tile layers.

Column-Major Storage — Explained

In a row-major array (like most 2D grids people think of), row Y of the grid comes after row Y-1. Tiles at the same Y coordinate are adjacent in memory.

The BLP format uses column-major storage instead. Column X of the grid comes after column X-1. Tiles at the same X coordinate (same column) are adjacent in memory. 

// Column-major layout for a 4×3 grid:
// Memory order: (0,0) (1,0) (2,0) (3,0) (0,1) (1,1) ...
// — all of column 0 first: (0,0), (0,1), (0,2)
// — then all of column 1: (1,0), (1,1), (1,2)
// — etc.

// Formula for BLP tile at (x, y) in a 100×100 grid:
index = y + 100 * x
byte_offset = index * 2   // each tile is 2 bytes (uint16)

Read: BLP → Tiled Foreground Layer

var layer = new TileLayer("Foreground");
var edit = layer.edit();

for (var x = 0; x < 100; x++) {
    for (var y = 0; y < 100; y++) {
        var fileOffset = 0x0364 + (y + 100 * x) * 2;
        var tileValue = file.readUint16(fileOffset);

        if (tileValue !== 0xFFFF) {
            // tileValue is the tile ID in object.tsx (0-based)
            edit.setTile(x, y, objectTileset.tile(tileValue));
        }
        // else: empty cell — setTile not called = transparent
    }
}
edit.apply();

Write: Tiled Foreground Layer → BLP

for (var x = 0; x < 100; x++) {
    for (var y = 0; y < 100; y++) {
        var fileOffset = 0x0364 + (y + 100 * x) * 2;
        var tile = foregroundLayer.tileAt(x, y);

        if (tile !== null) {
            file.writeUint16(tile.id, fileOffset);
        } else {
            file.writeUint16(0xFFFF, fileOffset);  // empty
        }
    }
}

Decoration Layer

The decoration layer uses the identical read/write logic, with the only differences being:

  • Base offset: 0x5184 instead of 0x0364
  • Tileset: explo.tsx instead of object.tsx
  • Layer name: "Decoration"

Empty Cell Value

0xFFFF (65535) is the empty cell sentinel value. When the extension reads this value, it leaves the Tiled cell empty (transparent). When writing an empty Tiled cell (no tile placed), it writes 0xFFFF to the file.

Tile ID Mapping

The BLP tile value is the direct tile ID in the corresponding Tiled tileset. There is no additional mapping — if the BLP contains tile value 42, tile ID 42 from the object tileset is placed in Tiled. If you have tile 42 selected in Tiled and paint it, value 42 is written to the BLP file.
