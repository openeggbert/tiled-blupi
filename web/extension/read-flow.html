Read Flow

A step-by-step walkthrough of what happens when sblv.js reads a BLP level file. This is the code executed by Tiled when you open a .blp file.

Entry Point

Tiled calls sblvMapFormat.read(fileName) where fileName is the absolute path to the BLP file. The function must return a TileMap object.

Step 1: Open the File

var file = new BinaryFile(fileName, BinaryFile.ReadOnly);

Opens the BLP file for binary reading. If the file cannot be opened, Tiled shows an error.

Step 2: Validate major_version

var majorVersion = file.readInt32(0x00);
if (majorVersion !== 1) {
    tiled.log("Error: major_version is " + majorVersion + ", expected 1");
    file.close();
    return null;
}

Reads the 4-byte signed integer at offset 0x00 and checks it is 1. If not, the extension logs an error and returns null, causing Tiled to report an error to the user.

Step 3: Read Header Fields

var minorVersion = file.readInt32(0x04);
var horzScroll   = file.readInt32(0x08);
var vertScroll   = file.readInt32(0x0C);
var music        = file.readInt32(0x10);
var background   = file.readInt32(0x14);
var name         = file.readString(0x18, 40);

All integers are 32-bit signed little-endian. The name is read as a 40-byte null-terminated string.

Step 4: Create the TileMap

var map = new TileMap();
map.setSize(100, 100);
map.setTileSize(64, 64);

// Set all header fields as custom map properties:
map.setProperty("major_version", majorVersion);
map.setProperty("minor_version", minorVersion);
map.setProperty("horz_scroll", horzScroll);
map.setProperty("vert_scroll", vertScroll);
map.setProperty("music", music);
map.setProperty("background", background);
map.setProperty("name", name.replace(/\0/g, ""));

Step 5: Read and Create the Foreground Layer

var foreground = new TileLayer("Foreground");
var objectTileset = tiled.mapFormatForFile(fileName)
    .tileset("object");  // (simplified — actual code resolves the tileset path)

var changes = foreground.edit();
for (var x = 0; x < 100; x++) {
    for (var y = 0; y < 100; y++) {
        var offset = 0x0364 + (y + 100 * x) * 2;
        var tileId = file.readUint16(offset);
        if (tileId !== 0xFFFF) {
            changes.setTile(x, y, objectTileset.tile(tileId));
        }
    }
}
changes.apply();
map.addLayer(foreground);

The foreground layer is created first. Each of the 100×100 cells is read using the column-major formula. Non-empty cells get a tile from the object tileset. The Tiled API requires using an edit batch (layer.edit() / apply()) for efficiency.

Step 6: Read and Create the Decoration Layer

Same process as foreground, but starting at offset 0x5184 and using the explo tileset:

var decoration = new TileLayer("Decoration");
// … same loop, but:
var offset = 0x5184 + (y + 100 * x) * 2;
var tileId = file.readUint16(offset);
// uses explo tileset tiles

Step 7: Read and Create the Objects Layer

var objects = new ObjectGroup("Objects");
for (var i = 0; i < 200; i++) {
    var base = 0x9FA4 + i * 0x30;
    var typeId = file.readInt32(base + 0x00);
    if (typeId === 0) continue;  // empty slot

    var enumIdx = itemTypesArray.indexOf(typeId);
    // create a MapObject with correct tile and properties…
    var obj = new MapObject();
    obj.x = file.readInt32(base + 0x0C) * 64;
    obj.y = file.readInt32(base + 0x10) * 64;
    // … set properties from remaining fields …
    objects.addObject(obj);
}
map.addLayer(objects);

All 200 slots are iterated. Empty slots (typeId == 0) are skipped. Non-empty slots create a MapObject at pixel position (x×64, y×64). The tile used for the object depends on whether it's a player start (200–203) or a regular object (uses enumIdx as tile ID).

Step 8: Load and Add the Background Image Layer

The extension constructs the background image filename from the background property and the game folder's IMAGE16/ or IMAGE08/ directory. It creates an ImageLayer and adds it at the bottom of the layer stack.

Step 9: Close the File and Return

file.close();
return map;

The file is closed and the completed TileMap is returned to Tiled.
