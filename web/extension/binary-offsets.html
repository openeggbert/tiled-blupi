Tile Layer Access Formula

For both foreground and decoration layers, given tile column x and row y:

// Foreground:
absolute_offset = 0x0364 + (y + 100 * x) * 2

// Decoration:
absolute_offset = 0x5184 + (y + 100 * x) * 2

// Both use the same column-major formula
