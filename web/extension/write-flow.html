Write Flow

A step-by-step walkthrough of what happens when sblv.js writes a Tiled map to a BLP file. This is executed when you use File → Save in Tiled.

Entry Point

Tiled calls sblvMapFormat.write(map, fileName) where map is the current TileMap and fileName is the path to write to.

Step 1: Open File for Writing

var file = new BinaryFile(fileName, BinaryFile.WriteOnly);

Opens the output file for binary writing. The previous file content is discarded.

Step 2: Write Header Fields

file.writeInt32(map.property("major_version") || 1, 0x00);
file.writeInt32(map.property("minor_version") || 2, 0x04);  // (3 for SB2)
file.writeInt32(map.property("horz_scroll")   || 0, 0x08);
file.writeInt32(map.property("vert_scroll")   || 0, 0x0C);
file.writeInt32(map.property("music")         || 0, 0x10);
file.writeInt32(map.property("background")    || 0, 0x14);

var name = map.property("name") || "";
file.writeString(name.substring(0, 39), 0x18);
// null-pad to 40 bytes

Step 3: Zero the Unknown Header Region

// Write zeros from 0x40 to 0x363 (804 bytes):
for (var i = 0x40; i < 0x364; i++) {
    file.writeByte(0, i);
}

This is a known limitation — the 804 bytes between the name field and the foreground layer are written as zeros because their structure is unknown.

Step 4: Write the Foreground Tile Layer

var foreground = map.layerAt(map.indexOfLayer("Foreground"));
for (var x = 0; x < 100; x++) {
    for (var y = 0; y < 100; y++) {
        var offset = 0x0364 + (y + 100 * x) * 2;
        var tile = foreground.tileAt(x, y);
        var tileId = (tile !== null) ? tile.id : 0xFFFF;
        file.writeUint16(tileId, offset);
    }
}

Empty cells (no tile in Tiled) are written as 0xFFFF.

Step 5: Write the Decoration Tile Layer

Same process as foreground, but at base offset 0x5184 and using the Decoration layer.

Step 6: Write the Object Array

var objectLayer = map.layerAt(map.indexOfLayer("Objects"));
var objectCount = 0;

for each object in objectLayer:
    if (objectCount >= 200) break;   // hard limit

    var base = 0x9FA4 + objectCount * 0x30;
    var enumIdx = obj.property("type");
    var typeId = itemTypesArray[enumIdx];

    file.writeInt32(typeId,                          base + 0x00);
    // bytes +0x04 to +0x09: write zeros
    file.writeUint16(obj.property("field_A") || 0,  base + 0x0A);
    file.writeInt32(Math.floor(obj.x / 64),         base + 0x0C);
    file.writeInt32(Math.floor(obj.y / 64),         base + 0x10);
    var ep = obj.property("endpoint") || {x:0, y:0};
    file.writeInt32(ep.x,                           base + 0x14);
    file.writeInt32(ep.y,                           base + 0x18);
    file.writeUint16(obj.property("a_to_b_time")||0, base + 0x1C);
    file.writeUint16(obj.property("b_to_a_time")||0, base + 0x1E);
    file.writeUint16(obj.property("a_wait")||0,     base + 0x20);
    file.writeUint16(obj.property("b_wait")||0,     base + 0x22);
    // … remaining fields …
    objectCount++;

// Fill remaining slots with zeros:
for (; objectCount < 200; objectCount++) {
    var base = 0x9FA4 + objectCount * 0x30;
    // write 0x30 zeros
}

Step 7: Write Trailing Zeros and Commit

// Zero the trailing unknown section:
for (var i = 0xC324; i < 50468; i++) {
    file.writeByte(0, i);
}
file.commit();

commit() flushes all pending writes and closes the file.

Important Notes

  • Objects beyond the 200th are silently dropped.
  • The entire output file is written from scratch — old content is not preserved.
  • Unknown regions (0x40–0x363 and 0xC324+) are always zeroed, overwriting any original data.
  • Pixel positions from Tiled are divided by 64 to convert back to tile coordinates.
