Object Conversion

Detailed explanation of how game objects are converted between the binary BLP object struct and Tiled objects, in both the read and write directions.

The Object Array

The BLP file contains an array of 200 object slots starting at offset 0x9FA4. Each slot is exactly 48 bytes (0x30). A slot is empty if its type field (first 4 bytes) is zero. The extension processes all 200 slots but creates Tiled objects only for non-empty ones.

Read Direction: BLP → Tiled

For each object slot:

var base = 0x9FA4 + slotIndex * 0x30;
var typeId = file.readInt32(base + 0x00);

if (typeId === 0) continue;  // skip empty slots

var obj = new MapObject();

Position conversion:

var tileX = file.readInt32(base + 0x0C);
var tileY = file.readInt32(base + 0x10);
obj.x = tileX * 64;   // BLP tile coord → Tiled pixel coord
obj.y = tileY * 64;

Type resolution for regular objects:

var enumIdx = itemTypesArray.indexOf(typeId);
// enumIdx is the tile ID in Object Types.tsx
// Set the tile from Object Types tileset:
obj.tile = objectTypesTileset.tile(enumIdx);
obj.setProperty("type", enumIdx);

Type resolution for player starts (typeId 200–203):

if (typeId >= 200 && typeId <= 203) {
    obj.tile = playerStartTileset.tile(typeId - 200);
    // No "type" property needed — tile determines the player number
}

All other properties:

obj.setProperty("endpoint", {
    x: file.readInt32(base + 0x14),
    y: file.readInt32(base + 0x18)
});
obj.setProperty("a_to_b_time", file.readUint16(base + 0x1C));
obj.setProperty("b_to_a_time", file.readUint16(base + 0x1E));
obj.setProperty("a_wait",      file.readUint16(base + 0x20));
obj.setProperty("b_wait",      file.readUint16(base + 0x22));
obj.setProperty("field_A",     file.readUint16(base + 0x0A));
obj.setProperty("field_24",    file.readInt32(base + 0x24));
obj.setProperty("field_26",    file.readUint16(base + 0x26));
obj.setProperty("field_28",    file.readUint16(base + 0x28));
obj.setProperty("field_2E",    file.readUint16(base + 0x2E));
// tileset_id and tile_id preserved as properties

Write Direction: Tiled → BLP

var slotIndex = 0;
for each obj in objectLayer {
    if (slotIndex >= 200) break;
    var base = 0x9FA4 + slotIndex * 0x30;

    // Determine BLP type ID:
    var enumIdx = obj.property("type");
    var typeId = itemTypesArray[enumIdx];

    // Position (pixels → tiles):
    var tileX = Math.floor(obj.x / 64);
    var tileY = Math.floor(obj.y / 64);

    file.writeInt32(typeId, base + 0x00);
    // zero bytes +0x04 to +0x09
    file.writeUint16(obj.property("field_A") || 0, base + 0x0A);
    file.writeInt32(tileX, base + 0x0C);
    file.writeInt32(tileY, base + 0x10);
    var ep = obj.property("endpoint") || {x: 0, y: 0};
    file.writeInt32(ep.x, base + 0x14);
    file.writeInt32(ep.y, base + 0x18);
    // … other fields …
    slotIndex++;
}
// Zero remaining slots (slotIndex to 199)

Player Start Write

Player start objects (from Player Start.tsx tiles 0–3) are written with:

var typeId = 200 + playerStartTile.id;   // 200–203
file.writeInt32(typeId, base + 0x00);

Object Position Note

Tiled stores object positions as floating-point pixel coordinates. When dividing by 64, the extension uses integer division (Math.floor) to convert to tile coordinates. Objects placed at non-tile-aligned pixel positions in Tiled will be snapped to the nearest tile. Always use Snap to Grid in Tiled to avoid unintended snapping.
