Extension (sblv.js) Overview

The sblv.js file is the heart of tiled-blupi. It is a JavaScript Tiled scripted map format that teaches the Tiled editor how to read and write Speedy Blupi BLP level files. This section documents every aspect of the extension.

What is a Scripted Map Format?

Tiled supports extending its file format support through JavaScript plugins. When a project file's extensionsPath directory contains a .js file, Tiled executes it when the project is opened. The script can call tiled.registerMapFormat(id, format) to register a new format. The format object provides name, extension, read(), and write() functions that Tiled calls when opening or saving files in that format.

Two Implementations

tiled-blupi includes two separate sblv.js files — one per game:

FileFormat IDFormat nameLines
Speedy Blupi/tiled/extensions/sblv.jssblvSpeedy Blupi level513
Speedy Blupi II/tiled/extensions/sblv.jssb2lvSpeedy Blupi 2 level552

The two files share the same code structure. They differ in: the registered format ID, the number of entries in itemTypesArray, the default minor_version, and the write switch cases for the additional SB2 object types.
