Using Tiled with tiled-blupi

A practical guide to the Tiled map editor features that are most useful when editing Speedy Blupi levels — panels, tools, properties, and workflow.

The Tiled Interface

Tiled is a general-purpose map editor designed for tile-based 2D games. When you open a Speedy Blupi level, it creates a map with four layers and several custom map properties. The key interface areas are:

  • Canvas (centre) — the level grid where you see and edit tiles and objects.
  • Layers panel (right side or floating) — lists all layers; click a layer to make it active.
  • Tilesets panel (bottom right or tab) — shows available tilesets; click a tile to select it for painting.
  • Properties panel (left or floating) — shows properties for the selected object or, when nothing is selected, the map properties.
  • Project panel (left) — shows project folders (tilesets/ and DATA/).
  • Console — accessible via View → Views and Toolbars → Console; shows extension output and errors.

Opening a Level

  1. Make sure you have installed tiled-blupi and opened the .tiled-project file.
  2. Go to File → Open (Ctrl+O).
  3. Navigate to the game's DATA/ folder.
  4. Select a WORLD###.BLP or u###-###.blp file.
  5. When asked for the format, choose the correct one for your game.
Which files can you open?
Only open files named WORLD###.BLP (standard levels) or u###-###.blp (custom levels). The DATA folder contains other .blp files that are not level files. Opening them will produce errors.

Editing Tiles

Selecting a Layer

You must select the correct layer before editing. Click the layer name in the Layers panel:

  • Foreground — to edit the main gameplay tiles
  • Decoration — to edit background decoration tiles

You cannot edit the Background image layer (it is locked).

Selecting a Tile

Open the Tilesets panel. Each layer uses a different tileset:

  • Foreground → object tileset
  • Decoration → explo tileset

Click a tile in the Tilesets panel to select it, or click-drag to select a multi-tile stamp.

Painting Tools

Editing Objects

Selecting and Moving Objects

  1. Select the Objects layer.
  2. Choose the Select Objects tool (S).
  3. Click on an object to select it. Its properties appear in the Properties panel.
  4. Drag the object to move it to a new position. The position is quantised to 64-pixel (1-tile) grid steps in the BLP output.

Adding a New Object

  1. Select the Objects layer.
  2. In the Tilesets panel, switch to the Object Types tileset.
  3. Choose the Insert Tile Object tool.
  4. Click on the canvas to place the object.
  5. In the Properties panel, set the type property to the desired ObjectTypes enum value.
  6. Set any other properties (endpoint, motion timing fields, etc.) as needed.

Deleting an Object

Select the object and press Delete. The object slot is written as zeros (type=0) in the BLP file on the next save.

Editing Map Properties

Map properties (music, background, name, scroll flags) are edited in the Properties panel:

  1. Click on an empty part of the canvas (deselect all objects).
  2. The Properties panel shows the map's custom properties.
  3. Click a property value to edit it.

See Map Properties for descriptions of each field.

Saving a Level

  1. File → Save (Ctrl+S) — overwrites the original .blp file.
  2. File → Save As — saves to a new path; Tiled will ask for the format again.
No undo for saved files
Saving is permanent. Always keep a backup of the original level files before editing.

Useful Tiled Settings

  • View → Snapping → Snap to Grid — recommended; ensures objects align to 64-pixel tiles.
  • View → Show Grid — shows the tile grid on the canvas.
  • View → Zoom In/Out — use Ctrl+scroll to zoom. Levels are 100×100 tiles; zooming out helps with the big picture.
  • Map → Map Properties — alternative way to access map custom properties.

The Project Panel

When the .tiled-project is open, the Project panel shows two folders:

  • tilesets/ — all TSX tileset files. Double-click a tileset to open it (not usually needed for editing).
  • DATA (or ../DATA) — the game's level files. Double-click a .BLP file here to open it directly.

This makes it easy to switch between levels without navigating through File → Open each time.
